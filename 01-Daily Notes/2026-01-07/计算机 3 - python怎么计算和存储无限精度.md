## 核心思想：和小学竖式计算一样！

你小时候学的竖式加法：
```
    999
  + 123
  -----
   1122
```

每一位只能存 0-9，满 10 就进位。Python 的大整数原理**完全一样**，只是：
- 每一"位"不是 0-9，而是 **0 到 2³⁰-1**（约 10 亿）
- 满 2³⁰ 就进位

## 具体实现

### 1. 存储结构

```c
// CPython 源码简化版
struct PyLongObject {
    Py_ssize_t ob_size;    // 数组长度（负数表示负数）
    digit ob_digit[];      // 数字块数组，每块 30 位
};
```

### 2. 举例：存储 `123456789012345678901234567890`

```
这个数太大，一个 30 位（最大约 10 亿）装不下

拆分成多个块（用 2^30 = 1073741824 作为"基数"）：

123456789012345678901234567890 
= 块0 + 块1 × 2^30 + 块2 × 2^60 + ...

存储为数组：
ob_digit = [块0的值, 块1的值, 块2的值, ...]
ob_size = 3  (用了3个块)
```

这就像**超大进制**的数字表示！

## 3. 加法的实现

```python
# 伪代码：大整数加法
def bigint_add(a, b):
    result = []
    carry = 0  # 进位
    
    for i in range(max(len(a.digits), len(b.digits))):
        # 取对应位，没有就是 0
        x = a.digits[i] if i < len(a.digits) else 0
        y = b.digits[i] if i < len(b.digits) else 0
        
        sum_val = x + y + carry
        result.append(sum_val % (2**30))  # 当前位
        carry = sum_val // (2**30)        # 进位
    
    if carry:
        result.append(carry)
    
    return result
```

**和竖式加法完全一样，只是"满 2³⁰ 进一"！**

## 4. 乘法的实现

小学竖式乘法：
```
      123
    ×  45
    -----
      615   (123 × 5)
     492    (123 × 4，左移一位)
    -----
     5535
```

Python 大整数乘法也是类似的，但用了更高效的算法：

| 数字大小 | 使用的算法 | 复杂度 |
|----------|-----------|--------|
| 小数字 | 普通竖式乘法 | O(n²) |
| 中等数字 | **Karatsuba 算法** | O(n^1.58) |
| 超大数字 | **快速傅里叶变换 (FFT)** | O(n log n) |

### Karatsuba 算法（简化版）

```python
# 计算 x × y，假设各有 n 位
def karatsuba(x, y):
    # 把 x 和 y 各拆成两半
    # x = a * 2^m + b
    # y = c * 2^m + d
    
    # 只需要 3 次乘法（而不是 4 次）
    ac = karatsuba(a, c)
    bd = karatsuba(b, d)
    ad_plus_bc = karatsuba(a + b, c + d) - ac - bd
    
    return ac * 2^(2m) + ad_plus_bc * 2^m + bd
```

**核心技巧**：用 3 次递归乘法代替 4 次，降低复杂度！

## 总结

| 概念 | 解释 |
|------|------|
| **基本思想** | 用数组存储，每个元素存 30 位，满了就进位 |
| **加法** | 逐位相加，进位，和竖式一样 |
| **乘法** | 小数用竖式，大数用 Karatsuba/FFT |
| **存储** | 动态数组，按需增长 |

本质就是**用软件模拟你在纸上做的竖式计算**，只是每一"位"能存更大的数（2³⁰ 而不是 10），配合高效算法！
