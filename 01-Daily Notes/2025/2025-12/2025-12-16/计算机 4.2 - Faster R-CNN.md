# Faster R-CNN：两次“框 → 向量 → 线性头”的流水线

## 一、先给一句“总纲式描述”（先立骨架）

> **Faster R-CNN 本质上是：  
> 在同一张特征图上，  
> 先跑一次“粗检测器”产生框，  
> 再跑一次“精检测器”给框分类和微调。**

或者更工程一点：

```
整图 CNN 一次
→ RPN：生成一堆候选框
→ RoI Pooling：每个框 → 一个固定长度向量
→ 分类 + 回归
→ NMS
```

只要你把 RPN 当成“一个自动的 Selective Search”，整个结构立刻清楚。

---

## 二、第一阶段：RPN 到底在“跑什么”？

你现在的描述把 RPN 讲成了“概念集合”，我们把它**还原成算子级流程**。

---

### Step 0：共享特征图（非常关键）

```
输入图像
→ Backbone CNN（VGG / ResNet）
→ Feature Map（H × W × C）
```

⚠️ 到这里为止：

- **RPN 和 Fast R-CNN 用的是同一张特征图**
- 没有重复计算

---

### Step 1：在特征图上“铺一张 Anchor 网格”

这一步你讲得是对的，但我们要给它一个**明确的工程角色**。

在 Feature Map 的每一个空间位置 ((i, j))：

- 放 (k = 9) 个 anchor
- 每个 anchor 是一个“假想框”
- 映射回原图后，就相当于：

```
特征点 (i,j)
→ 9 个不同大小/比例的候选框
```

👉 **Anchor 本质上是：  
“把连续的框搜索空间，离散成有限个参考模板”**

---

### Step 2：RPN 的一次前向传播（核心）

对 Feature Map 做一次：

```
3×3 conv（共享）
→ 得到一个中间特征
```

然后分成两个 **1×1 conv 分支**：

#### ① Anchor 是否是“物体”的分类分支

```
1×1 conv
→ 输出 H × W × (2k)
```

解释成工程语言：

- 对每个 anchor
- 输出 2 个分数：
    - foreground
    - background

---

#### ② Anchor 怎么修的回归分支

```
1×1 conv
→ 输出 H × W × (4k)
```

这一步你要**强烈类比 R-CNN**：

> **和 R-CNN / Fast R-CNN 的 Bounding Box Regression 完全同构**  
> 只是：
> 
> - 输入不再是 4096-d 向量
>     
> - 而是一个局部卷积特征
>     

---

### Step 3：Anchor → Proposal（这一步常被跳过）

这是很多讲解最模糊的地方。

对每一个 anchor：

1. 用回归分支输出的  
    ((t_x, t_y, t_w, t_h))
    
2. 应用到 anchor 上
3. 得到一个 **修正后的框**

```
Anchor
→ (dx,dy,dw,dh)
→ Proposal
```

👉 **到这里，RPN 的使命完成：  
它输出的是一堆“已经粗对齐”的框坐标**

---

### Step 4：RPN 内部的 NMS（重要但常被忽略）

- 所有 proposal 数量巨大（2 万 +）
- 按前景分数排序
- 做一次 NMS
- 保留 top-N（如 2000 / 300）

👉 **这一步的输出，语义上等价于：  
Selective Search 的输出**

---

## 三、第二阶段：Fast R-CNN 在这些 Proposal 上“精修”

从这里开始，**你可以完全复用 Fast R-CNN 的理解**。

---

### Step 5：Proposal → RoI Pooling

```
Proposal 框
→ 映射到 Feature Map
→ RoI Pooling
→ 固定尺寸特征块
→ FC
→ 4096-d 向量
```

⚠️ 注意这个对称性：

- RPN：  
    特征图 → 框
    
- Fast R-CNN Head：  
    框 → 向量

---

### Step 6：最终分类与精回归

```
4096-d
→ 分类头（C+1）
→ 回归头（4C）
```

- 分类：猫 / 狗 / 车 / 背景
- 回归：再修一次框（比 RPN 更准）

---

### Step 7：最终 NMS

- 按类别
- 对最终检测框做 NMS
- 输出结果

---

## 四、把 Faster R-CNN 压缩成一条“你会觉得清楚的话”

现在你可以用一句非常“R-CNN 风格”的话来描述它：

> **Faster R-CNN =  
> 整图 CNN 一次 →  
> RPN 在特征图上生成候选框 →  
> 每个候选框 RoI Pooling 得到 4096-d →  
> 一个线性层分类 →  
> 一个线性层精修 →  
> NMS**
