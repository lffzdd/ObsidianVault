# 套入公式

> [!question]
> 假设原分布是 [0,0,1,0,0]
> 预测分布是 [0,0.1,0.8,0,0.1]
> 
> 那么我要让中间那个 0.8 靠近 1，这里怎么套入到最大化似然公式那一套

这个问题问得太好了，这是把**抽象公式**落地到**具体数值**的最关键一步。

我们手里有两个向量：

- **真实分布（事实 $y$）**：$[0, 0, 1, 0, 0]$ —— 这代表第 3 类发生了（比如图片是“猫”）。
- **预测分布（模型 $\hat{y}$）**：$[0, 0.1, 0.8, 0, 0.1]$ —— 模型说它是猫的概率是 0.8。

要把这个例子套进 **“最大化似然（MLE）”** 的公式里，其实只需要三步。你会发现，看似复杂的向量运算，其实是一个**“自动筛选器”**。

---

### 第一步：找回“似然”的定义

**似然（Likelihood）** 的定义是：**“在参数 $\theta$ 下，观测到当前真实数据发生的概率”。**

在这个例子里，“当前真实数据”是什么？

是 **“第 3 类发生了”**。

那么，“观测到第 3 类发生的概率”是多少？

看你的预测分布，模型说第 3 类发生的概率是 **0.8**。

所以，在这个瞬间，**似然值就是 0.8**。

$$Likelihood = 0.8$$

我们的目的（MLE）：**调整参数，让这个 0.8 变大，尽可能接近 1。**

---

### 第二步：用数学公式实现“自动筛选”

虽然我们肉眼一眼就看出来似然是 0.8，但机器不知道它是第几个。我们需要一个通用的数学公式，不管正确答案在第几位，都能自动把这个概率值（0.8）给“抠”出来。

这个公式利用了 **$y$ 是 One-hot 编码（只有 1 个是 1，其他是 0）** 的特性。

似然函数 $L(\theta)$ 可以写成**连乘**的形式（这是多项式分布的似然）：

$$L(\theta) = \hat{y}_1^{y_1} \times \hat{y}_2^{y_2} \times \hat{y}_3^{y_3} \times \hat{y}_4^{y_4} \times \hat{y}_5^{y_5}$$

把你的数字带进去：

$$L(\theta) = 0^0 \times 0.1^0 \times 0.8^1 \times 0^0 \times 0.1^0$$

请注意数学上的两个性质：

1. 任何数的 0 次方都等于 1 ($x^0 = 1$)。
2. 任何数的 1 次方都等于它本身 ($x^1 = x$)。

于是公式变成了：

$$L(\theta) = 1 \times 1 \times 0.8 \times 1 \times 1 = 0.8$$

**看到了吗？**

通过这个指数运算，那些对应 $y=0$ 的错误项（比如 0.1 和 0），全部变成了 **1**（乘法中的透明人，不起作用）。

只有对应 $y=1$ 的那一项（0.8），因为指数是 1，被原封不动地保留了下来。

这就是**似然函数**在多分类问题中的真面目。

---

### 第三步：变身为交叉熵（取对数）

我们想要 **最大化** 这个 $0.8$。

但在工程上，我们更习惯 **最小化 Loss**，并且把乘法变成加法（方便求导）。

所以我们对上面的连乘公式取 **负对数（-log）**：

$$Loss = - \log(L(\theta)) = - \log( \hat{y}_1^{y_1} \times \hat{y}_2^{y_2} \times \hat{y}_3^{y_3} \times \hat{y}_4^{y_4} \times \hat{y}_5^{y_5} )$$

根据对数性质 $\log(a \times b) = \log a + \log b$ 和 $\log(a^b) = b \log a$：

$$Loss = - \left[ y_1 \log(\hat{y}_1) + y_2 \log(\hat{y}_2) + y_3 \log(\hat{y}_3) + y_4 \log(\hat{y}_4) + y_5 \log(\hat{y}_5) \right]$$

再次把你的数字代进去：

$$Loss = - [ 0 \cdot \log(0) + 0 \cdot \log(0.1) + 1 \cdot \log(0.8) + 0 \cdot \log(0) + 0 \cdot \log(0.1) ]$$

因为 0 乘以任何数都是 0，所以这一长串最后只剩下：

$$Loss = - [ 1 \cdot \log(0.8) ] = - \log(0.8)$$

---

### 这里的关键问题：其他的 0.1 去哪了？

你可能会问：**“我的目的是让 0.8 变大，但我不需要把其他的 0.1 变小吗？在这个公式里，其他的 0.1 好像直接被 0 乘掉了，完全没参与计算啊？”**

这又是一个极好的直觉。

在**交叉熵公式本身**里，它确实**只关心**正确答案的那一项（0.8）。它根本不看错误答案是多少。

但是，**为什么训练时其他 0.1 会变小呢？**

这是因为你的预测分布 $\hat{y}$ 通常是由 **Softmax 函数** 生成的。

Softmax 强制要求：所有概率加起来必须等于 1。

$$\hat{y}_1 + \hat{y}_2 + \hat{y}_3 + \hat{y}_4 + \hat{y}_5 = 1$$

这是一个**零和游戏**。

当你用 MLE（交叉熵）拼命把 $\hat{y}_3$ (0.8) 往上拉的时候，为了保持总和为 1，其他的 $\hat{y}$ (0.1) 就**被迫**被挤下去了。

### 总结

1. **似然 (Likelihood)**：就是那个 **0.8**。
2. **公式 (Mathematics)**：用 $P(\text{data}|\theta) = \prod \hat{y}_i^{y_i}$ 这个公式，利用 $y_i$ 的 0 和 1 属性，把 0.8 从数组里“筛选”出来。
3. **优化 (Optimization)**：最大化 0.8 $\Leftrightarrow$ 最小化 $-\log(0.8)$。

所以，你只要盯着那个 **0.8**，想办法让它变大，就是在做**最大似然估计**。

# 解读

这个困惑非常经典！你之所以觉得别扭，是因为在**硬币例子**和**神经网络例子**中，$\theta$ 和 $P(x|\theta)$ 的**表现形式**变了，导致你找不到对应的位置了。

我们要把这两个例子放在显微镜下，一一对应，你立刻就通了。

---

### 1. 硬币例子 vs 神经网络例子：一一映射

让我们严格对应每一个符号。

#### **场景 A：投硬币（简单的单参数模型）**

- **事实 $x$**：你看到了一次“正面”（我看到了 7 正 3 反）。(对应你说的 10 次里的某一次)。
- **模型参数 $\theta$**：硬币本身的物理构造（决定了它出正面的概率是 0.1 还是 0.9）。我们通常直接用 $p$ 来代表这个参数。
- **预测输出**：基于当前参数 $p$，模型说：“这次出正面的概率是 $p$”。
- **似然 $P(x|\theta)$**：
    - 既然事实 $x$ 是正面。
    - 模型预测正面的概率是 $p$。
    - 所以 **似然 = $p$**。

#### **场景 B：神经网络分类（复杂的多参数模型）**

- **事实 $x$**：你看到了这张图是 **“第 3 类”**（对应标签向量 `[0,0,1,0,0]` 里的那个 1）。
- **模型参数 $\theta$**：几百万个权重 ($w_1, w_2, ...$)。
- **预测输出**：基于当前权重，模型输出了一组概率 `[0, 0.1, 0.8, 0, 0.1]`。
- **似然 $P(x|\theta)$**：
    - 既然事实 $x$ 是“第 3 类”。
    - 模型预测第 3 类的概率是 0.8。
    - 所以 **似然 = 0.8**。

---

### 2. 核心疑问：“既有预测的 0.8 又有真实的 1，怎么看？”

这里的 **“真实的 1”** 和 **“预测的 0.8”** 分工是非常明确的，它们在似然函数里扮演不同的角色：

1. **真实的 1 ($x$)：它是“选路牌”（Selector）。**
    
    它告诉你：“嘿！别看第 1、2、4、5 个数了，它们都是干扰项！**只看第 3 个数！**”
    
    它的作用就是**定位**。它不是概率值，它是事实的**指路人**。
    
2. **预测的 0.8 ($P$ output)：它是“被评分的对象”。**
    
    这是模型在“选路牌”指出的那个位置上，交出的答卷。

**把它们合起来看 $P(x|\theta)$：**

- **$x$ (事实)** 问：“我真的是第 3 类（1），你觉得我是第 3 类的概率是多少？”
- **$\theta$ (模型)** 答：“我觉得是 0.8。”
- **结果：** 似然值就是 0.8。

> **比喻：**
> 
> - **$x$ (真实的 1)** 就像是**考试的标准答案**，上面写着：“第 3 题选 C”。
>     
> - **$\theta$ (预测分布)** 就像是**你填的答题卡**，你在 A 填了 0%，B 填了 10%，C 填了 80%...
>     
> - **似然 $P(x|\theta)$** 就是**老师改卷**：老师看标准答案是 C（这是 $x$），然后看你在 C 选项上的信心是 80%（这是预测），所以给你打分 0.8 分。
>     

---

### 3. 为什么硬币例子里没有“真实的 1”？

其实硬币例子里也有！只是公式写得太简化，把你“骗”了。

在硬币例子里，如果 $x=1$ 代表正面，$x=0$ 代表反面。

似然函数的**完整写法**其实是（伯努利分布）：

$$P(x|\theta) = p^x \cdot (1-p)^{1-x}$$

你看这里：

- 如果事实是正面 ($x=1$)：$P = p^1 \cdot (1-p)^0 = p$。
    - 这里 $x=1$ 也是起到了“选路牌”的作用，它把 $(1-p)$ 这一项消掉了，只留下了 $p$。
- 如果事实是反面 ($x=0$)：$P = p^0 \cdot (1-p)^1 = 1-p$。
    - 这里 $x=0$ 把 $p$ 消掉了，留下了 $1-p$。

**结论：**

- 在硬币例子里，**$x$ (1 或 0)** 负责选择是保留 $p$ 还是 $1-p$。
- 在神经网络里，**$x$ ([0,0,1,0,0])** 负责选择是保留 0, 0.1, **0.8**, 0 还是 0.1。

**它们在逻辑上是完全一模一样的。** 只是神经网络是个“多面骰子”，硬币是个“两面骰子”。

### 总结

- **x (发生的事)**：是指 **“标签是第 3 类”** 这件事发生了。
- **P(x|theta)**：是指 **“模型预测第 3 类发生的概率”**（即 0.8）。
- **真实的 1**：用来告诉你**去读哪个数**。
- **预测的 0.8**：就是**读出来的那个数**（似然值）。

你要让似然最大，就是**想办法调整参数，让那个 0.8 变成 0.99**。
