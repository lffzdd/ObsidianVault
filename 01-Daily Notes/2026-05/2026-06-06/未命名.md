## pathlib

> 你在 `tools.py` 里用的 `Path(__file__).resolve().parent / "workspace"` 就是 pathlib。

### 核心概念

```python
from pathlib import Path

p = Path("/some/dir/file.txt")
```

### 你用过的 / 最常见的方法

| 方法 | 含义 | 你代码中的例子 |
|------|------|----------------|
| `Path(__file__)` | 当前 .py 文件的路径 | `tools.py` 第 190 行 |
| `.resolve()` | 转为绝对路径，消除 `..` | `Path(__file__).resolve()` |
| `.parent` | 上一级目录 | `.resolve().parent` → 文件所在目录 |
| `p / "subdir"` | 路径拼接（不用 `os.path.join`） | `WORKSPACE_DIR / path` |
| `.is_relative_to(base)` | 检查是否在 base 目录下（安全沙箱用） | `_safe_path()` 里的防路径穿越 |
| `.iterdir()` | 列出目录下所有条目（生成器） | `list_files()` 里用到 |
| `.is_file()` / `.is_dir()` | 判断是文件还是目录 | `list_files()` 里过滤 |
| `.name` | 只要文件名（不含路径） | `entry.name` |
| `.stem` | 文件名，不含扩展名 | `Path("foo.py").stem` → `"foo"` |
| `.suffix` | 扩展名 | `Path("foo.py").suffix` → `".py"` |
| `.exists()` | 路径是否存在 | 写文件前先判断 |
| `.read_text(encoding="utf-8")` | 读文件内容为字符串 | 替代 `open().read()` |
| `.write_text(content, encoding="utf-8")` | 写字符串到文件 | 替代 `open().write()` |
| `.mkdir(parents=True, exist_ok=True)` | 创建目录（含父目录，已存在不报错） | 初始化工作区 |
| `.glob("**/*.py")` | 递归找所有 .py 文件 | 见 [glob 章节](#glob) |

### 常用片段

```python
# 你在 tools.py 里的沙箱路径模式（防路径穿越）
WORKSPACE_DIR = Path(__file__).resolve().parent / "workspace"

def _safe_path(path: str) -> Path:
    safe_path = (WORKSPACE_DIR / path).resolve()
    if not safe_path.is_relative_to(WORKSPACE_DIR):
        raise ValueError("Unsafe path")
    return safe_path

# 读文件
content = Path("config.json").read_text(encoding="utf-8")

# 写文件
Path("output.txt").write_text("hello", encoding="utf-8")

# 递归列出所有 Python 文件
for f in Path(".").rglob("*.py"):
    print(f)

# 创建多级目录
Path("a/b/c").mkdir(parents=True, exist_ok=True)
```

## glob

> 用于文件名模式匹配。两种用法：`pathlib` 的 `.glob()` 和标准库 `glob` 模块。

### 通配符语法

| 符号 | 含义 | 例子 |
|------|------|------|
| `*` | 匹配任意字符（不含目录分隔符） | `*.py` → 当前目录所有 .py |
| `**` | 递归匹配任意深度目录 | `**/*.py` → 所有子目录的 .py |
| `?` | 匹配单个任意字符 | `file?.txt` → file1.txt, fileA.txt |
| `[abc]` | 匹配括号中任意一个字符 | `[abc].py` → a.py, b.py, c.py |

### 用 pathlib（推荐）

```python
from pathlib import Path

root = Path("/Users/slyh/MyDir/Project/LLM")

# 当前目录下所有 .py
list(root.glob("*.py"))

# 递归所有 .py（包括子目录）
list(root.rglob("*.py"))
# 等价于
list(root.glob("**/*.py"))

# 所有 tools.py 文件
list(root.rglob("tools.py"))

# 过滤出真正存在的文件（排除目录）
[f for f in root.rglob("*.py") if f.is_file()]
```

### 用标准库 glob 模块

```python
import glob

# 注意：glob 返回字符串列表，不是 Path 对象
files = glob.glob("src/**/*.py", recursive=True)
```

> **记忆规律**：`glob()` 只找当前层，`rglob()` 递归所有层。想递归就加 `r`。

## rg

> `rg` 是 ripgrep，速度极快，用于在项目里搜索代码内容。比 `grep` 快很多。

### 最常用的 rg 命令

```bash
# 在当前目录递归搜索字符串
rg "tool_registry"

# 搜索特定文件类型
rg "def " --type py

# 显示行号（默认就有）
rg "httpx" -n

# 只显示文件名（不显示匹配内容）
rg "Tool" -l

# 搜索时忽略大小写
rg "react" -i

# 显示匹配行的前后 N 行上下文
rg "raise_for_status" -C 3      # 上下各 3 行
rg "raise_for_status" -B 2 -A 5  # 前 2 行，后 5 行

# 排除某些目录（如 node_modules, __pycache__）
rg "import" --glob "!__pycache__/**"

# 只搜索特定路径
rg "Tool" src/Agent/

# 搜索正则表达式
rg "def \w+_tool"   # 找所有 xxx_tool 函数定义

# 结合 -l 和 -t 快速定位文件
rg "WORKSPACE_DIR" -l --type py
```

### 在 Python 里调用 rg（给 Agent 用）

```python
import subprocess

def rg_search(pattern: str, path: str = ".", file_type: str = None) -> str:
    cmd = ["rg", pattern, path, "-n"]
    if file_type:
        cmd += ["--type", file_type]
    result = subprocess.run(cmd, capture_output=True, text=True)
    return result.stdout
```

### rg vs grep 对比

| 特性 | rg | grep |
|------|----|----|
| 速度 | 极快（多线程） | 慢 |
| 默认递归 | ✅ | ❌（需要 `-r`） |
| 自动忽略 `.gitignore` | ✅ | ❌ |
| Unicode 支持 | ✅ | 有限 |

## httpx

> 你在 `tools.py` 里用 `httpx` 做 HTTP 请求。

### 基础用法

```python
import httpx

# GET 请求
resp = httpx.get("https://ifconfig.me", timeout=20)

# POST 请求（JSON body）— 你的 web_search 用的就是这个
resp = httpx.post(
    url="https://api.tavily.com/search",
    headers={"Authorization": "Bearer xxx", "Content-Type": "application/json"},
    json={"query": "2024 Olympics"},  # 自动设置 Content-Type: application/json
    timeout=20,
)

# POST 请求（raw string body）
resp = httpx.post(url="...", content="raw string body")

# 通用 request（你在 http_request_tool 里用的）
resp = httpx.request("GET", url, params={"key": "value"}, headers={}, timeout=20)
```

### 请求参数速查

| 参数 | 类型 | 含义 |
|------|------|------|
| `params` | `dict` | URL 查询参数（?key=value） |
| `json` | `dict` | JSON body，自动设 Content-Type |
| `content` | `str/bytes` | 原始 body，不做处理 |
| `data` | `dict` | 表单格式（application/x-www-form-urlencoded） |
| `headers` | `dict` | 请求头 |
| `timeout` | `float` | 超时秒数 |

### 响应处理

```python
resp.raise_for_status()          # 4xx/5xx 抛异常（你的代码里用到了）

resp.status_code                 # 状态码，如 200
resp.headers                     # 响应头字典
resp.headers.get("content-type") # 读某个响应头（你的代码里用到了）
resp.text                        # 响应体字符串
resp.json()                      # 解析 JSON（你的代码里用到了）
resp.content                     # 响应体 bytes
```

### 你的 http_request 函数核心逻辑回顾

```python
# body 是 dict → 用 json= 参数（自动加 Content-Type: application/json）
# body 是 str  → 用 content= 参数（原始字符串）
if isinstance(body, dict):
    kwargs["json"] = body
elif isinstance(body, str):
    kwargs["content"] = body

resp = httpx.request(method, url, **kwargs)
resp.raise_for_status()

# 根据 content-type 决定如何解析
body = resp.json() if "application/json" in content_type else resp.text
```

### 异步 httpx（写 async Agent 时用）

```python
import httpx
import asyncio

async def fetch():
    async with httpx.AsyncClient() as client:
        resp = await client.get("https://ifconfig.me", timeout=20)
        return resp.text
```

## json

> 你在 `main.py` 里大量用到 json，包括解析 LLM 回复和序列化工具结果。

### 四个核心函数

| 函数 | 方向 | 说明 |
|------|------|------|
| `json.loads(s)` | 字符串 → Python | 解析 JSON 字符串 |
| `json.dumps(obj)` | Python → 字符串 | 序列化为 JSON |
| `json.load(f)` | 文件 → Python | 从文件对象读取 |
| `json.dump(obj, f)` | Python → 文件 | 写入文件对象 |

### 常用参数

```python
# ensure_ascii=False → 中文不转义（你的代码里用到了）
# indent=2          → 格式化输出（你的代码里用到了）
json.dumps(messages, ensure_ascii=False, indent=2)

# 解析 LLM 返回的 JSON（你的 llm_json_parser）
start = content.index("{")   # 第一个 {
end = content.rindex("}")    # 最后一个 }
json.loads(content[start:end+1])
```

## subprocess

> 在 Agent 里运行命令行工具（如 rg、git、python 脚本）。

### 最常用：`subprocess.run`

```python
import subprocess

# 运行命令，捕获输出
result = subprocess.run(
    ["rg", "tool_registry", ".", "-n"],  # 命令列表（不要用字符串）
    capture_output=True,   # 捕获 stdout 和 stderr
    text=True,             # 输出为字符串（而不是 bytes）
    cwd="/some/dir",       # 工作目录（可选）
)

result.stdout    # 标准输出字符串
result.stderr    # 标准错误字符串
result.returncode  # 0 表示成功

# 失败时抛异常
result.check_returncode()
# 或
subprocess.run([...], check=True)
```

### 给 Agent 工具用的封装模式

```python
def run_command(cmd: list[str], cwd: str = None) -> dict:
    try:
        result = subprocess.run(
            cmd, capture_output=True, text=True, cwd=cwd, timeout=30
        )
        return {
            "ok": result.returncode == 0,
            "stdout": result.stdout,
            "stderr": result.stderr,
        }
    except subprocess.TimeoutExpired:
        return {"ok": False, "stdout": "", "stderr": "Timeout"}
    except FileNotFoundError as e:
        return {"ok": False, "stdout": "", "stderr": str(e)}
```

## os

> 主要用于读环境变量，你在 `main.py` 里用了这个。

```python
import os

# 读环境变量（你的代码里用到了）
os.getenv("OPENAI_API_KEY")           # 不存在返回 None
os.getenv("OPENAI_MODEL") or "gpt"    # 不存在时用默认值
os.environ["TAVILY_API_KEY"]          # 不存在会抛 KeyError（你的 tools.py 里用了这个）
```

> **规律**：`os.getenv` 安全，不存在返回 None；`os.environ[...]` 强制要求存在，适合必须有的 key。

## 快速参考：Agent 文件操作工具模板

以下是基于你现有 `tools.py` 扩展的常用文件操作模板，可以直接加到你的工具注册表里：

```python
from pathlib import Path

# 读文件
def read_file(path: str) -> dict:
    try:
        content = _safe_path(path).read_text(encoding="utf-8")
        return {"ok": True, "content": content}
    except Exception as e:
        return {"ok": False, "err": str(e), "content": ""}

# 写文件
def write_file(path: str, content: str) -> dict:
    try:
        p = _safe_path(path)
        p.parent.mkdir(parents=True, exist_ok=True)
        p.write_text(content, encoding="utf-8")
        return {"ok": True}
    except Exception as e:
        return {"ok": False, "err": str(e)}

# 搜索文件内容（调用 rg）
def search_in_files(pattern: str, directory: str = ".") -> dict:
    try:
        safe_dir = _safe_path(directory)
        result = subprocess.run(
            ["rg", pattern, str(safe_dir), "-n", "--type", "py"],
            capture_output=True, text=True, timeout=15
        )
        return {"ok": True, "matches": result.stdout}
    except Exception as e:
        return {"ok": False, "err": str(e), "matches": ""}

# 列出文件（含递归）
def find_files(pattern: str = "**/*.py", directory: str = ".") -> dict:
    try:
        safe_dir = _safe_path(directory)
        files = [str(f.relative_to(WORKSPACE_DIR)) for f in safe_dir.glob(pattern) if f.is_file()]
        return {"ok": True, "files": files}
    except Exception as e:
        return {"ok": False, "err": str(e), "files": []}
```
