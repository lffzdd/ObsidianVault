这个问题问得特别关键——它戳到了"理论"和"代码"之间那道最容易被忽略的缝。**几乎所有讲正则历史的材料都会跳过它，直接从 Kleene 切到 Thompson，仿佛中间没发生什么**。其实中间发生了大事，而且不是一个人、不是一天、也不是一开始就奔着状态机去的。我们一步一步还原。

## 先把"那个年代的程序员"还原回去

要回答"最开始是怎么想的"，得先把你从今天的视角里拽出来。1960 年代中期写正则的人，脑子里**没有**"正则是个用来匹配字符串的小工具"这个先验印象——这个印象是 Thompson 之后才让全世界有的。他们脑子里有的是另外两样东西，**正是这两样东西决定了最早的代码长什么样**：

一是 Kleene 那篇论文。他们读过、知道"正则事件 = 有限自动机能识别的模式"这个数学定理，但这定理在他们眼里更像一个**关于可计算性的哲学声明**,而不是一份施工图。Kleene 的证明是非构造性的味道很浓——他告诉你"存在一台机器",但没告诉你"给我一个正则,我怎么把那台机器**画出来**"。

二是当时正在出的一些早期编辑器/匹配器的代码。**而这些代码,绝大多数,真的就是按你说的那个"朴素想法"写的。**

所以答案的第一层是:**最早的实现,确实不是从状态机出发的**。状态机这一层是后来被"逼"上去的,而且逼上去的人,正是 Thompson。我们顺序看。

## 第一阶段(大约 1960—1965):朴素递归——"边读模式边比"

最早能在真实机器上跑的正则匹配器,思路质朴到让人感动,基本就是你猜的那个味道:

> 我有一个字符串 s,一个模式 p,我想知道 p 配不配得上 s。那我就**两个指针并排往前走**:p 的当前字符如果是普通字符,就跟 s 当前字符比一下,对就一起往前挪一格,不对就失败;碰到 `*` 这种特殊符号,就**先猜一下**——猜它匹配 0 个、1 个、2 个……每种猜法都试着往下走,有一种走通就赢。

代码长这样(伪代码,精神上是 1960 年代很多匹配器的真身):

```
match(p, s):
    if p 为空: return s 为空
    if p[1] 是 '*' 修饰前一个字符 c:
        # 猜:c 重复 0 次?重复 1 次?重复 2 次?...
        for k = 0, 1, 2, ...:
            if s 前 k 个都是 c 且 match(p 去掉 c*, s 跳过 k 个):
                return true
        return false
    else:
        return s[0] == p[0] 且 match(p[1:], s[1:])
```

这就是**朴素的递归回溯匹配**。

```python
# 最朴素的起点：逐字符比较，支持 . 和 *

def match(pattern, text):
    # 模式用完了，文本也得用完才算配上
    if pattern == "":
        return text == ""

    # ---- 新东西：看看是不是 c* 的形式 ----
    if len(pattern) >= 2 and pattern[1] == '*':
        c = pattern[0]         # 被 * 修饰的字符
        rest = pattern[2:]     # c* 之后的剩余模式

        # 猜 0 次：直接跳过 c*，拿 rest 去配剩下的 text
        if match(rest, text):
            return True

        # 猜 1+ 次：当前字符得对上 c，吃掉它，c* 留着继续猜
        if text != "" and (c == '.' or c == text[0]):
            return match(pattern, text[1:])

        return False

    # ---- 原来的逻辑：普通字符 / . ----
    if text == "":
        return False
    if pattern[0] == '.' or pattern[0] == text[0]:
        return match(pattern[1:], text[1:])
    return False

# 试试
print("--- 基本 ---")
print(match("abc", "abc"))     # True
print(match("a.c", "abc"))     # True

print("--- * 重复 ---")
print(match("a*",   ""))       # True  -- 0 个 a
print(match("a*",   "a"))      # True  -- 1 个 a
print(match("a*",   "aaa"))    # True  -- 3 个 a
print(match("a*b",  "b"))      # True  -- 0 个 a + b
print(match("a*b",  "aab"))    # True  -- 2 个 a + b
print(match("a*b",  "aac"))    # False

print("--- .* 万能 ---")
print(match(".*",   "anything"))  # True  -- .* 吃掉一切
print(match("a.*c", "abcdc"))     # True

```
