# 自己推导

假设我们想要计算一个离散函数的和：

$$S(n) = \sum_{i=0}^{n} f(i) = f(0) + f(1) + \dots + f(n)$$
有 $$S(x)-S(x-1)=f(x)$$
将 $S(x-1)$ 在 $x$ 处展开：
$$S(x-1) = S(x) - \frac{S'(x)}{1!} + \frac{S''(x)}{2!} - \frac{S'''(x)}{3!} + \dots$$

代入 $S(x) - S(x-1) = f(x)$ 中：
$$S(x) - \left( S(x) - S'(x) + \frac{1}{2}S''(x) - \frac{1}{6}S'''(x) + \dots \right) = f(x)$$

得 $$f(x)=S'(x) - \frac{1}{2}S''(x) + \frac{1}{6}S'''(x) - \frac{1}{24}S^{(4)}(x) + \dots$$
看出 $f(x)$ 对应 $S'(x)$，$S(x)$ 是 $f(x)$ 的高一阶项，假设：$$S(x) = \int f(x)dx + k_{0} f(x) + k_{1} f'(x) + k_{2} f''(x) + k_{3} f'''(x) + \dots$$
则有：
1. $S'(x)=f(x)+k_{0}f'(x)+k_{1}f''(x)+k_{2}f'''(x)+\cdots$
2. $S''(x)= \qquad\qquad f'(x)+k_{0}f''(x)+k_{1}f'''(x)+\cdots$
3. $S'''(x)= \qquad\qquad\qquad\qquad f''(x)+k_{0}f'''(x)+\cdots$
4. $S^{(4)}(x)= \qquad\qquad\qquad\qquad\qquad f'''(x)+\cdots$

代入 $f(x)=S'(x) - \frac{1}{2}S''(x) + \frac{1}{6}S'''(x) - \frac{1}{24}S^{(4)}(x) + \dots$ 中，得：
$$
\begin{align}
f(x) &= \left( f(x)+k_{0}f'(x)+k_{1}f''(x)+k_{2}f'''(x)+\cdots \right) - \frac{1}{2}\left( f'(x)+k_{0}f''(x)+k_{1}f'''(x)+\cdots \right) + \frac{1}{6}\left( f''(x)+k_{0}f'''(x)+\cdots \right) - \frac{1}{24}\left( f'''(x)+\cdots \right) + \dots \\
&= f(x) + \left( k_{0} - \frac{1}{2} \right) f'(x) + \left( k_{1} - \frac{1}{2}k_{0} + \frac{1}{6} \right) f''(x) + \left( k_{2} - \frac{1}{2}k_{1} + \frac{1}{6}k_{0} - \frac{1}{24} \right) f'''(x) + \dots

\end{align}
$$
令各阶导数系数为 0，得：
$$
\begin{align}
k_{0} - \frac{1}{2} &= 0 \\
k_{1} - \frac{1}{2}k_{0} + \frac{1}{6} &= 0 \\
k_{2} - \frac{1}{2}k_{1} + \frac{1}{6}k_{0} - \frac{1}{24} &= 0 \\ \\
\cdots \\  \\
k_{n} - \frac{1}{2}k_{n-1} + \frac{1}{3!}k_{n-2} - \frac{1}{4!}k_{n-3} + \dots + \frac{(-1)^{n}}{(n+1)!} &= 0
\end{align}
$$
解得：$$
\begin{align}
k_{0} &= \frac{1}{2} \\
k_{1} &= \frac{1}{12} \\
k_{2} &= 0 \\
k_{3} &= -\frac{1}{720} \\
k_{4} &= 0 \\
k_{5} &= \frac{1}{30240} \\
\cdots \\
\end{align}$$
最终得出麦克劳林公式：
$$S(n) = \int f(x)dx + \frac{1}{2} f(n) + \frac{1}{12} f'(n) - \frac{1}{720} f'''(n) + \frac{1}{30240} f^{(5)}(n) + \dots$$

$$

# Gemini

这是一个非常迷人的思维挑战。为了满足“不使用超出当时时代的知识”这一约束，我们将回到 18 世纪 30 年代。

此时，**莱昂哈德·欧拉 (Leonhard Euler)** 刚刚抵达圣彼得堡，而**科林·麦克劳林 (Colin Maclaurin)** 正在爱丁堡撰写他的巨著。当时没有现代的收敛性定义，没有复变函数论中的留数定理，也没有抽象代数。

当时的数学核心工具是：

1. **泰勒级数 (Taylor Series, 1715)**：将函数展开为无穷级数。
2. **微积分 (Calculus)**：牛顿和莱布尼茨发明的微分与积分符号。
3. **形式幂级数 (Formal Power Series)**：当时的数学家习惯大胆地操作无穷级数，相信运算的形式美。
4. **伯努利数 (Bernoulli Numbers)**：雅各布·伯努利在研究幂和问题时发现的一组神秘系数。

我们将采用欧拉在 1736 年左右的思路（后来在他的《微分学基础》中详细阐述），使用**待定系数法**结合**泰勒级数**来“自底向上”地推导这个公式。

---

### 第一步：问题的定义与直觉

假设我们想要计算一个离散函数的和：

$$S(n) = \sum_{i=0}^{n} f(i) = f(0) + f(1) + \dots + f(n)$$

欧拉的直觉告诉他，求和 ($\sum$) 与积分 ($\int$) 是紧密相关的。积分是求和的连续形式。因此，离散的和 $S(n)$ 应该等于连续的积分加上一些“修正项”。

我们假设存在一个可微函数 $S(x)$，使得当 $x$ 为整数 $n$ 时，$S(n)$ 就是我们要的累加和。根据求和的定义，这个函数必须满足**差分性质**：

$$S(x) - S(x-1) = f(x)$$

_(注：这里的意思是，当前的累加和减去上一步的累加和，等于当前的项。)_

### 第二步：利用泰勒级数连接“离散”与“连续”

我们要处理的是 $S(x-1)$。在 18 世纪，处理 $x-1$ 这种偏移量的标准武器是**泰勒级数**。

我们将 $S(x-1)$ 在 $x$ 处展开：

$$S(x-1) = S(x) - \frac{S'(x)}{1!} + \frac{S''(x)}{2!} - \frac{S'''(x)}{3!} + \dots$$

将这个展开式代入我们的差分方程 $S(x) - S(x-1) = f(x)$ 中：

$$S(x) - \left( S(x) - S'(x) + \frac{1}{2}S''(x) - \frac{1}{6}S'''(x) + \dots \right) = f(x)$$

化简去掉 $S(x)$：

$$S'(x) - \frac{1}{2}S''(x) + \frac{1}{6}S'''(x) - \frac{1}{24}S^{(4)}(x) + \dots = f(x)$$

这是一个关于未知函数 $S(x)$ 的无穷阶微分方程。我们的目标是反解出 $S(x)$。

### 第三步：构造解的形式 (待定系数法)

因为 $S'(x)$ 是主要项（它对应于积分），我们假设 $S(x)$ 的解是由积分项和一系列导数项组成的：

$$S(x) = \int f(x)dx + A f(x) + B f'(x) + C f''(x) + D f'''(x) + \dots$$

其中 $A, B, C, D \dots$ 是我们需要确定的常数系数。

为了求出这些系数，我们对假设的解求导，分别计算 $S'(x), S''(x), \dots$：

1. $S'(x) = f(x) + A f'(x) + B f''(x) + C f'''(x) + \dots$
2. $S''(x) = \quad \quad \quad f'(x) + A f''(x) + B f'''(x) + \dots$
3. $S'''(x) = \quad \quad \quad \quad \quad \quad f''(x) + A f'''(x) + \dots$

现在，将这些导数回代到**第二步**得到的方程中：

$$\left( f + Af' + Bf'' + \dots \right) - \frac{1}{2}\left( f' + Af'' + \dots \right) + \frac{1}{6}\left( f'' + \dots \right) - \dots = f(x)$$

### 第四步：比较系数

为了让等式对任意 $f(x)$ 成立，我们必须让 $f(x)$ 及其各阶导数的系数在左右两边相等。

**1. 比较 $f(x)$ 的系数：**

左边：$1$ （来自 $S'(x)$ 的第一项）

右边：$1$

_结论：匹配成功（这是因为我们将积分作为了首项）。_

**2. 比较 $f'(x)$ 的系数：**

左边：$A - \frac{1}{2}$

右边：$0$

$$A - \frac{1}{2} = 0 \implies A = \frac{1}{2}$$

**3. 比较 $f''(x)$ 的系数：**

左边：$B - \frac{1}{2}A + \frac{1}{6}$

右边：$0$

$$B - \frac{1}{2}(\frac{1}{2}) + \frac{1}{6} = 0$$

$$B - \frac{1}{4} + \frac{1}{6} = 0 \implies B = \frac{3}{12} - \frac{2}{12} = \frac{1}{12}$$

**4. 比较 $f'''(x)$ 的系数：**

左边：$C - \frac{1}{2}B + \frac{1}{6}A - \frac{1}{24}$

右边：$0$

$$C - \frac{1}{2}(\frac{1}{12}) + \frac{1}{6}(\frac{1}{2}) - \frac{1}{24} = 0$$

$$C - \frac{1}{24} + \frac{2}{24} - \frac{1}{24} = 0 \implies C = 0$$

此时，我们得到的解的形式是：

$$S(x) = \int f(x)dx + \frac{1}{2}f(x) + \frac{1}{12}f'(x) + 0 \cdot f''(x) + \dots$$

### 第五步：伯努利数的显现

敏锐的 18 世纪数学家（如欧拉）此时会认出这些系数。

我们刚才做的系数匹配过程，本质上是在寻找一个级数的倒数。

回忆一下方程：

$$(1 - \frac{D}{2!} + \frac{D^2}{3!} - \dots) S'(x) = f(x)$$

其中 $D$ 是微分算子。

这意味着 $S'(x) = \frac{1}{1 - \frac{D}{2!} + \frac{D^2}{3!} - \dots} f(x)$。

如果我们将这个算子写成 $ \frac{D}{e^{-D} - 1} $（利用泰勒级数 $e^{-x} = 1 - x + x^2/2 - \dots$），我们实际上是在寻找生成函数的系数。

这正是**伯努利数 (Bernoulli Numbers, $B_k$)** 的定义来源：

$$\frac{t}{e^t - 1} = \sum_{k=0}^{\infty} B_k \frac{t^k}{k!}$$

_(注：当时的伯努利数定义符号可能略有不同，但数值是一致的：$B_0=1, B_1=-1/2, B_2=1/6, B_4=-1/30 \dots$)_

通过严格的代数比对，我们刚才算出的系数 $A, B, C \dots$ 正好对应于 $\frac{B_k}{k!}$ 的形式（稍作符号调整）。

最终，欧拉得出了通项公式：

$$S(x) = \int f(x)dx + \frac{1}{2}f(x) + \frac{B_2}{2!}f'(x) + \frac{B_4}{4!}f'''(x) + \frac{B_6}{6!}f^{(5)}(x) + \dots$$

_(注意：$B_3, B_5$ 等奇数项伯努利数为 0，这也是为什么刚才算出 $C=0$)_

### 第六步：定积分形式（定界）

我们上面求的是不定积分形式。现在我们要计算区间 $[0, n]$ 上的和：

$$\sum_{i=0}^{n} f(i) = S(n) - S(0) + f(0)$$

_(这里有一个细微的边界处理，通常我们计算 $\sum_{i=a}^{b} f(i)$)_

让我们将公式应用于区间 $[a, b]$。

我们知道 $\int_{a}^{b} f(x)dx = F(b) - F(a)$。

利用刚才推导的 $S(x)$ 表达式，我们可以写出：

$$\sum_{i=a}^{b} f(i) = \int_{a}^{b} f(x)dx + \frac{1}{2}(f(b) + f(a)) + \sum_{k=1}^{\infty} \frac{B_{2k}}{(2k)!} \left( f^{(2k-1)}(b) - f^{(2k-1)}(a) \right)$$

这就是著名的**欧拉 - 麦克劳林公式**。

### 历史总结

欧拉通过这种**形式化算子法**（将微分算子 $D$ 视为代数变量进行倒数运算），极其优雅地从“离散差分”推导出了“连续积分”与“导数修正项”之间的关系。

虽然在当时他没有证明这个级数通常是发散的（这是 19 世纪柯西之后的事了），但他极其敏锐地指出：**这个级数不能加到无穷项，必须在某处截断并估计余项**，这使得该公式在数百年后依然是数值计算（如计算 $\pi$ 或 $\zeta$ 函数）的神器。
