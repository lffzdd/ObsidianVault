## 解决方案：字符串类型注解

### ✅ 正确做法

```python
class BPETokenizer:
    def __init__(self, vocab: "Vocab"):  # ✅ 使用字符串
        self.vocab = vocab
```

**为什么有效？**
- 字符串 `"Vocab"` 不会被立即解析
- Python 会**延迟求值**（lazy evaluation），在实际需要类型检查时才解析
- 这样即使 [Vocab](cci:2://file:///f:/Projects/llm/src/my_transformer/_1_tokenizer.py:234:0-293:20) 类在后面定义也没问题

## 总结：为什么用字符串 `"Vocab"` 作为类型注解

### 核心原因：**前向引用问题**

| 情况 | 写法 | 原因 |
|------|------|------|
| **类还未定义** | `vocab: "Vocab"` | 必须用字符串，否则 `NameError` |

| **类已在前面定义** | `vocab: Vocab` | 可以不用引号 |
