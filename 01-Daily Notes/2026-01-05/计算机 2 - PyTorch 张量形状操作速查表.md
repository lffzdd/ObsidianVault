## PyTorch 张量形状操作速查表

### 核心：只有 5 个常用的！

| 方法 | 作用 | 记忆口诀 |
|------|------|----------|
| `view` / `reshape` | 重塑形状（总元素数不变） | "**捏橡皮泥**" |
| `squeeze` | 删除大小为 1 的维度 | "**挤掉 1**" |
| `unsqueeze` | 在指定位置添加大小为 1 的维度 | "**加个 1**" |
| `transpose` | 交换两个维度 | "**两维换位**" |
| `permute` | 重新排列所有维度 | "**全部重排**" |

---

### 1. `view` / `reshape` - 捏橡皮泥

```python
x = torch.randn(2, 3, 4)  # 24 个元素

x.view(6, 4)      # [6, 4] - 6×4=24 ✅
x.view(2, 12)     # [2, 12] - 2×12=24 ✅
x.view(24)        # [24] - 展平
x.view(2, -1)     # [2, 12] - -1 表示自动计算
x.view(2, 3, 2, 2) # [2, 3, 2, 2] - 拆分维度
```

**记忆：总数不变，随便捏形状**

---

### 2. `squeeze` - 挤掉 1

```python
x = torch.randn(1, 3, 1, 4)  # 形状 [1, 3, 1, 4]

x.squeeze()     # [3, 4] - 挤掉所有的 1
x.squeeze(0)    # [3, 1, 4] - 只挤第 0 维的 1
x.squeeze(2)    # [1, 3, 4] - 只挤第 2 维的 1
```

**记忆：专门消灭维度为 1 的**

---

### 3. `unsqueeze` - 加个 1

```python
x = torch.randn(3, 4)  # 形状 [3, 4]

x.unsqueeze(0)   # [1, 3, 4] - 在第 0 维加 1
x.unsqueeze(1)   # [3, 1, 4] - 在第 1 维加 1
x.unsqueeze(-1)  # [3, 4, 1] - 在最后加 1
```

**记忆：在指定位置插入一个 1**

---

### 4. `transpose` - 两维换位

```python
x = torch.randn(2, 3, 4)  # [2, 3, 4]

x.transpose(0, 1)   # [3, 2, 4] - 交换第 0 和第 1 维
x.transpose(1, 2)   # [2, 4, 3] - 交换第 1 和第 2 维
x.transpose(-2, -1) # [2, 4, 3] - 交换最后两维（常用！）
```

**记忆：只能交换两个维度**

---

### 5. `permute` - 全部重排

```python
x = torch.randn(2, 3, 4)  # [2, 3, 4]
#                维度:     0  1  2

x.permute(1, 0, 2)   # [3, 2, 4] - 把维度 1 放第一，0 放第二，2 放第三
x.permute(2, 0, 1)   # [4, 2, 3]
x.permute(0, 2, 1)   # [2, 4, 3] - 等价于 transpose(1, 2)
```

**记忆：全部维度重新排列**

---

## 对比图

```
原始: [2, 3, 4]

view(6, 4):        [6, 4]       ← 重塑
view(2, 3, 2, 2):  [2, 3, 2, 2] ← 拆分

squeeze:   只能删除大小为 1 的维度
unsqueeze: 只能添加大小为 1 的维度

transpose(1, 2):   [2, 4, 3]    ← 只换两维
permute(2, 0, 1):  [4, 2, 3]    ← 全部重排
```

## 在多头注意力中的应用

```python
# 当前形状
Q: [batch, seq, head * k_dim]  # [2, 10, 512]

# 用 view 拆分
Q = Q.view(batch, seq, head, k_dim)  # [2, 10, 8, 64]

# 用 transpose 换位
Q = Q.transpose(1, 2)  # [2, 8, 10, 64]

# 计算完后用 transpose 换回来
output = output.transpose(1, 2)  # [2, 10, 8, 64]

# 用 view 合并
output = output.view(batch, seq, -1)  # [2, 10, 512]
```

## 记忆技巧

| 需求 | 用什么 |
|------|--------|
| 改变形状（元素总数不变） | `view` |
| 加一个维度 | `unsqueeze` |
| 删一个维度（大小为 1） | `squeeze` |
| 交换两个维度 | `transpose` |
| 重排所有维度 | `permute` |

**只需要记住这 5 个，覆盖 99% 的场景！** 🎯
