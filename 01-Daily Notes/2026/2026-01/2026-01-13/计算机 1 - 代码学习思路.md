## Problem Explanation

The error **"Undefined name `self`"** at line 76 occurs because you're using `self.pair_freq` as a **default argument value** in the function definition:

```python
def _update_merge_pair(self, pair_freq: Counter = self.pair_freq):
```

In Python, **default argument values are evaluated at function *definition* time**, not at function *call* time. When Python parses this function definition, `self` doesn't exist yet—it only becomes available when the method is actually called. Therefore, `self.pair_freq` cannot be used as a default value.

The solution uses the `None` sentinel pattern:
