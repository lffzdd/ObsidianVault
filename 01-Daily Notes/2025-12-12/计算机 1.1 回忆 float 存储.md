# 实例：将 12.375 转换为 32 位 Float

**第一步：转换为二进制**

首先，将十进制数 12.375 转换为二进制。

- 整数部分 12 的二进制是 1100。
- 小数部分 0.375 的二进制是 0.011。

所以，12.375 的二进制表示为 $1100.011_2$。

**第二步：规范化 (Normalization)**

为了使用 IEEE 754 标准，我们需要将二进制数写成科学记数法（即 $1.XXXXX \times 2^Y$ 的形式）。

$$1100.011_2 = 1.100011_2 \times 2^3$$

现在，我们确定了公式所需的几个关键部分：

- **符号 (S):** 数是正数 (12.375)，所以**符号位 S = 0**。
- **指数的幂 (Y):** 移动小数点后得到的幂是 3。
- **尾数 (M):** 小数点后面的部分是 100011。

**第三步：填充尾数 (Mantissa / Significand)**

尾数需要占据 23 位。我们取规范化后的 1.100011 中小数点后的部分，并用零在右侧补齐到 23 位。

$$\text{尾数 (M)} = 10001100000000000000000$$

(注意：前面的那个隐藏的 `1` 是不存储的。)

**第四步：计算指数 (Exponent)**

指数需要占据 8 位，并且需要使用**偏移量（Bias）**计算。对于 32 位 float，偏移量是 127。

- 实际的指数幂 $Y = 3$。
- 需要存储的指数值 $E = Y + \text{Bias} = 3 + 127 = 130$。

将十进制数 130 转换为 8 位二进制：

$$130_{10} = 10000010_2$$

- **指数 (E):** 10000010

# 结果：32 位 Float 表示

将这三部分按顺序组合起来：[符号位] [8 位指数] [23 位尾数]

|**部分**|**二进制值**|
|---|---|
|**符号位 (S)**|0|
|**指数 (E)**|10000010|
|**尾数 (M)**|10001100000000000000000|

最终，十进制数 12.375 在内存中的 32 位二进制表示为：

$$0 \enspace 10000010 \enspace 10001100000000000000000$$

# 如何反向读取？

当你读取这段二进制数据时，计算机会执行以下操作：

1. **看符号位：** 是 `0`，所以是正数。
2. **看指数：** `10000010` 转换成十进制是 130。减去偏移量 127，得到实际指数是 $130 - 127 = 3$。
3. **看尾数：** `100011...` 。在前面加上隐藏的 `1` ，得到 $1.100011_2$。
4. **组合：**
    
    $$1.100011_2 \times 2^3 = 1100.011_2 = 12.375_{10}$$
