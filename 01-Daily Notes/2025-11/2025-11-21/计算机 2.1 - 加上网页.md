# 【下一步要做的三件小事】

## 1. 在 app 层添加一个新路由 `/page/preview`（返回 HTML）

在 `app/app.py` 里加：

```python
from flask import Flask, render_template, jsonify
app = Flask(__name__, template_folder='templates')
```

然后加：

```python
@app.get("/page/preview")
def preview_page():
    return render_template("preview.html")
```

## 2. 新建一个 `templates/preview.html`

目录结构：

```
project/
  app/
    app.py
    templates/
      preview.html
```

preview.html 最简单可以长这样（我给你一个最小可用版本）：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>发券预览</title>
</head>
<body>
    <h2>发券预览</h2>

    <button onclick="loadPreview()">刷新</button>
    <button onclick="sendCoupons()">发券</button>

    <table border="1" id="orders">
        <thead>
            <tr>
                <th>选择</th>
                <th>trade_no</th>
                <th>金额</th>
                <th>品牌</th>
                <th>券名称</th>
                <th>券值</th>
            </tr>
        </thead>
        <tbody></tbody>
    </table>

<script>
async function loadPreview() {
    const res = await fetch("/preview");
    const json = await res.json();

    const table = document.querySelector("#orders tbody");
    table.innerHTML = "";

    json.data.forEach(item => {
        const tr = document.createElement("tr");

        tr.innerHTML = `
            <td><input type="checkbox" value="${item.trade_no}"></td>
            <td>${item.trade_no}</td>
            <td>${item.recharge_amount}</td>
            <td>${item.sub_brand_name}</td>
            <td>${item.coupon_name}</td>
            <td>${item.coupon_value}</td>
        `;
        table.appendChild(tr);
    });
}

async function sendCoupons() {
    const checks = document.querySelectorAll("input[type=checkbox]:checked");
    let trade_nos = Array.from(checks).map(c => c.value);

    const res = await fetch("/send", {
        method: "POST",
        headers: {"Content-Type": "application/json"},
        body: JSON.stringify({trade_nos})
    });

    const json = await res.json();
    alert(JSON.stringify(json));
}

window.onload = loadPreview;
</script>

</body>
</html>
```

这是一个极简网页：

- 自动加载预览列表
- 有复选框
- 有发券按钮
- 最终跳转调用你的 `/send`
- 不依赖 Vue/React
- 属于纯 HTML + JS，适合你这个工具性质的系统

完全够用，而且清晰、可控。

# 🎯 为什么这一步非常重要？

你刚才问过：

> 后端为什么返回 json，而不是直接返回网页？

现在你会明白：

- **API 层（返回 json）** 是核心业务接口，未来脚本、系统、前端都能用
- **页面层（返回 html）** 是给人类看的界面，本质上也是调用 API

结构是：

```
       前端页面       ←—— JS 调用 ——→    JSON API
            ↑                                ↑
            |                                |
          人类                         系统/脚本/前端
```

这就是一个成熟系统的标准结构。
