我们进入**第四课：需求曲线是怎么“长出来”的**。  
前面三课已经搭好了基础机器：偏好、预算、无差异曲线、最优点。  
现在我们要把这台机器“启动”，让它自动产出一个现实世界里最重要的对象：

> **需求曲线：价格下降 → 需求增加，价格上升 → 需求减少**
> 
> 经济学的关键不是这个“结论”，而是：  
> **为什么它会从“最优选择模型”里自然长出来？**

这堂课就是把“需求曲线”从图形角度、逻辑角度、历史演化角度讲透。

---

# 一、需求曲线不是凭空来的，而是“最优选择随价格变化的轨迹”

先回忆上一课的图：

- 有一条预算线
- 有一族无差异曲线
- 最优消费点是在预算线的切点

现在，如果我们把 X 商品的价格 (p_x) 慢慢降低：

- 预算线的**X 截距向外推（变长）**
- 预算线的斜率变“没那么陡”（绝对值变小）
- 切点会跟着移动

**这个切点移动的轨迹，就是 X 的需求曲线。**

用一张示意图来看（不严格比例，只展示结构）：

```text
    Y
    ^
    |         U3
    |        *****
    |   U2 **      *
    |     *  ●(p2)  *
    |   *     .       * 
    | *   (p1)  ●       *
    +---------------------------> X
         预算线1    预算线2

```

- 当价格是 p1 → 预算线比较“陡”→ 最优点在左边（X 买得少）
- 当价格下降到 p2 → 预算线变“平”→ 切点向右移动（X 买得多）

如果你把最优点的 X 坐标记录下来，并把“价格 vs 最优数量”画到另一张图上：

```text
   价格 p_x
      ^
p1 ---●
      |
p2 -------●
      |
      +-----------------> X数量
           x2     x1
```

就得到了**一条向右下倾斜的需求曲线**。

这是“需求曲线的生成逻辑”——不是凭直觉画出来的，而是从“最优选择”推出来的。

---

# 二、为什么价格降低，会让你买更多 X？（底层逻辑）

需求曲线为什么向右下倾斜？经济学把理由拆成两类：

## 1. 替代效应（Substitution Effect）

逻辑从“相对价格变化”出发。

如果：

- X 变便宜了
- Y 的价格没变

那么：  
**X 相对 Y 来说变得更划算**

你自然会倾向于：

- 少买一点 Y
- 多买一点 X

这部分变化是纯粹因为“X 相对便宜了”，不是因为你变富了。

在图上，你会看到当预算线旋转但保持通过原最优点的“平行虚线”时，你在这条线上找到一个新的最优点——  
这就是替代效应的定义。

如果用图示意（非常简化版）：

```text
    Y
    ^
    |
    |        o（旧最优点）
    |      o  （替代效应后的点）
    |
    +------------------> X
```

画平行线、切点这些以后会具体推，这里先讲直觉。

## 2. 收入效应（Income Effect）

当 X 变便宜，你不花更多钱，但“能买得起的东西变多”，  
这等于你**“变富一点”**。

变富意味着——你可以走向更高层的无差异曲线。

结果是：

- 如果 X 是“正常品”（你变富会多买）→ 你会买更多 X
- 如果 X 是“劣等品”（你变富会少买）→ 你会买更少 X

日常例子：

- 泡面就是典型“劣等品”：有钱了就不吃那么多
- 咖啡、牛奶、衣服多数是正常品：有钱了会多买
- 奢侈品甚至有“凡勃伦效应”：价格越高买得越多，但那是特殊情况，我们下一节会讲“例外情况”。

---

# 三、把替代效应 + 收入效应组合起来，就是需求对价格的反应

整合逻辑：

- X 变便宜 → 替代效应：必然让你买更多 X
- X 变便宜 → 收入效应：如果 X 是正常品，也让你买更多 X
- 两者合起来 → 通常是 “价格下降 → 需求增加”

大部分商品都是正常品，所以需求曲线通常向下。

经济学的厉害之处是：  
它不是画一个直觉曲线，而是把“人的选择原理”从偏好和约束中推出来，然后自然得到：

> **价格越高 → 替代效应减少 X → 收入效应减少 X**

最终变成一条平滑向下的曲线。

---

# 四、用数学视角看：最优解如何随价格变化？

假设效用 (U(x, y) = x^\alpha y^\beta)（Cobb-Douglas，最常用的效用函数之一）。

我们知道最优点满足：

[  
\frac{MU_x}{MU_y} = \frac{p_x}{p_y}  
]

又因为：

- ( MU_x = \alpha x^{\alpha-1} y^\beta )
- ( MU_y = \beta x^\alpha y^{\beta-1} )

所以：

[  
\frac{\alpha y}{\beta x} = \frac{p_x}{p_y}  
]

再结合预算约束：

[  
p_x x + p_y y = M  
]

解出来（你很快能熟练推出来）：

[  
x^* = \frac{\alpha}{\alpha + \beta} \cdot \frac{M}{p_x}  
]

注意看这个式子：

- 随着价格 (p_x) 上升，需求 (x^*) 以“反比”下降
- 这就是一条严格的向下需求曲线

而且非常漂亮：  
**需求曲线 = 最优消费解对价格的函数**。

这就是“经济学的设计优雅性”：  
偏好 → 效用 → 一阶条件 → 最优解 → 需求曲线  
整个链条是紧密相连的。

---

# 五、需求曲线真正强大之处：它是“最优行为”的结果，而不是心理猜测

市场学可能说：

- “用户喜欢便宜的东西”
- “价格降了销量会上升”

经济学说：

> 你要讲清楚 “为什么”，而不是“看上去是这样”。

需求曲线不是经验曲线，而是：

- 从偏好逻辑出发
- 被预算约束裁切
- 再从优化问题里推导出来
- 最终是消费者 **在价格变化下的最优反应轨迹**

这就是为什么经济学能预测、解释、推理政策效果，因为它不是拍脑袋画线，而是一个逻辑系统。

# 六、小练习（依旧轻量，但非常关键）

假设你只消费两种东西：

- X：咖啡
- Y：饺子

你现在的预算线与最优点如图：

```text
   Y
   ^
   |         U2
   |        ****
   |      **   *
   |   U1*   ●   *
   +---------------------> X
          预算线
```

现在如果：

1. X（咖啡）涨价 20%
2. Y（饺子）不变价
3. 你对咖啡的偏好是“正常品”

请尝试想象：

- 预算线哪一端会“向内收缩”？
- 新的最优切点会在哪边？
- 因为替代效应你会怎么调？
- 因为收入效应你会怎么调？
- 最终咖啡的消费量会怎样变化？

你只要能自己画出新的预算线和最优点，你就已经真正“会用”需求曲线，而不是把它当死记的线条。
