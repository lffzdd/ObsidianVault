# 一、借和贷都用“钱”计数吗？

**是的。**

中世纪商人已经很清楚：

> 即使交易的是羊毛、布匹、香料、银器，账面记录必须统一用“货币金额”来计量。

原因很简单：

- 货物无法直接相加比较
    
- 货物价值需要与债务、应收、资本算在同一个系统里
    
- 只有统一成“货币价值”，才能进行**平衡校验**
    

所以：

无论买卖货物、支付运费、员工工资、借贷、折旧……  
**账的货币单位必须统一。**

# 二、卖 50 元布匹给乔瓦尼，究竟怎么记？

要区分两种情况：

---

## 情况 A：你“赊销”布匹（乔瓦尼还没付钱）

这是当时最常见的情况。

你得到了一个“乔瓦尼欠你 50”的权利，  
乔瓦尼获得了布匹；  
布匹离开了你这边。

在古代复式记账里：

### 1. 在“乔瓦尼”账户（属于人与人关系）

乔瓦尼欠你  
→ 属于你方的权利  
→ 记 **借（in dare）**

```
Giovanni di Pisa
借（In Dare）       | 贷（In Avere）
----------------------------------------
50（欠我布匹款）   |
```

### 2. “布匹（Merce）”账户（货物离开你）

布匹从你方转移到他方  
→ 属于“他方”的价值  
→ 记 **贷（in avere）**

```
Merce（布匹）
借（In Dare） | 贷（In Avere）
----------------------------------------
              | 50（发给乔瓦尼）
```

### 3. 借贷检查：

- 借方合计：50
    
- 贷方合计：50
    

**相等。**  
这笔账是平的。

你刚刚描述的“乔瓦尼借方 +50，布匹贷方 +50”**完全正确**（在赊销条件下）。

---

## 情况 B：你“现金销售”布匹（乔瓦尼当场付钱）

那就变成：

乔瓦尼不欠你钱 → 无需动乔瓦尼账户  
你只是：

- 拿到了 50 现金
    
- 布匹出了库
    

古代记法变成：

### 1. “现金（Cassa）”账户

现金属于你方 → 记借（in dare）

```
Cassa
借           | 贷
-------------------------
50（收现金） |
```

### 2. “布匹（Merce）”账户

布匹离开你 → 属于他方 → 记贷（in avere）

```
Merce
借           | 贷
-------------------------
             | 50（卖出布匹）
```

借 = 贷 = 50  
一样平。

# 三、所有账户的借方总额与贷方总额，一定要相等吗？

**是的，永远必须相等。**

这就是复式记账最核心的技术点，也是它得以流传千年的原因：

> 每一个事件，必然同时改变两个“价值归属”关系，金额必须相同但方向相反。

当时的商人没有“资产负债表”，  
但他们已经发现：

> **只要每天检查“借方合计 = 贷方合计”，账就不会乱。**

这就是后来的“试算平衡表”（Trial Balance）的前身。

为什么永远相等？

因为交易的本质是：

- 一方的减少 = 另一方的增加
    
- 一个对象转移到你的“拥有”，必然从另一个对象的“拥有”中消失
    
- 价值不可能凭空出现或消失
    

复式记账正是用“借 = 贷”来强制你保持这种**价值守恒**。

---

# 四、关键理解，一句话总结

你可以把古代复式记账的逻辑最终归纳为这句：

> **借 = 落在我方的价值，贷 = 落在他方的价值；  
> 每一笔交易都必须在两个对象的归属关系里写一遍，并保持金额相等。**
