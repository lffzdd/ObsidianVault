# Amia 春季系列 AI 女装宣传图标准模板（内部使用版）

适用品牌定位：法式 · 优雅 · 浪漫 · 中高端女装  
适用场景：官网 / 电商主图 / Lookbook / 门店物料 / 代理商画册  
推荐比例：16:9（1920×1080 或 2560×1440）

———

## 一、通用出图规范（所有模板通用）

### 1. 风格总原则
- 关键词：法式 / 优雅 / 浪漫 / 高级 / 克制
- 背景优先：纯白 / 米白 / 浅灰 / 简洁室内
- 光线：柔和自然光，避免强对比和硬阴影
- 模特：气质型脸，表情自然偏冷静，不夸张
- 构图：主体居中偏下，上方留白可放标题

### 2. 通用控制提示（强烈建议每张都加）

中文：
> 构图平衡，模特居中偏下站立，上方留有充足留白用于放置标题文字，干净高级构图

英文：
> centered composition, leave empty space at the top for title text, premium editorial layout
