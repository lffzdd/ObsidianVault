## 建议接手顺序

1. 先看 `00_开始这里/重点文件索引.md`，了解最值得继续用的产出。
2. 再看 `01_核心成果`，其中是数字化战略、门店客户运营、会员系统与网络安全资料。
3. 实际落地某个活动时，再进入 `02_业务项目` 查看完整过程。
4. 需要生成图片、提取商品标签或生成话术时，使用 `03_AI工具与内容模板`。
5. `90_过程稿_供追溯` 不建议直接对外发布，主要用于理解思路演进和找回旧版内容。

## 使用提醒

- 资料中有较多 AI 辅助生成内容，数据、行业案例、引用和预算在对外使用前需重新核验。

- 一处接口 Token 已在交接副本中脱敏。由于它曾以明文出现，建议系统负责人立即作废旧 Token 并重新签发。
