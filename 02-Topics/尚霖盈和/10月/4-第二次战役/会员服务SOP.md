# 二. 引流

### 周几流量最好？

- 根据测试，周三流量最好，周五流量差。

### 什么时间发布流量最好？

- 发布时间选择流量峰值：早7-9点，午12-14点，晚20-23点。

### 封面用什么流量最好？

- 封面点击率比静态封面高37%。

### 字符数限制

- 文字数最多可以放20个字；正文50-1000字均可。

### 素材（图片/视频）

- 图片数量≥3张；视频时长不超过5分钟；尺寸推荐：3:4。

### 服装行业爆款公式

- 搜索到+场景化解决方案（看得完）+三级标签（推荐）流量=精准标签。

## 3.1 沟通6部曲

1. **尊称问候**
	
	- 示例话术：“您好！蝴蝶女士！”
		
2. **自我介绍**
	
	- 示例话术：“我是d'zzit XXX店，我叫XXX，请问您现在在说话方便吗？”
		
3. **引起关注**
	
	- 示例话术：“有件比较重要的事情想跟你沟通，您是我们尊贵的VIP会员，我看到您喜欢的风衣已经到店了，而且下个月8号就是您的生日了。”
		
4. **吸引邀约**
	
	- 示例话术：“我们d'zzit现在有一个_**的活动；而且还能免费得到**_的礼品，看你什么时候方便来我们店看看？”
		
5. **确定时间**
	
	- 示例话术：“好的蝴蝶小姐姐，周五下午的两点时我准备您的到来，到时帮您停个车位，停车也方便。”
		
6. **加V结束沟通**
	
	- 示例话术：“感谢您的宝贵时间，为了方便联系我会用工作微信加您下，感谢您对d'zzit品牌的支持，祝您XXX，拜拜！”

## 3.3 邀约唤醒

| **邀约类型** | **描述**                |
| -------- | --------------------- |
| **新品邀约** | 向会员推荐符合其需求的新产品。       |
| **活动邀约** | 根据会员喜好邀请参与相关活动，提升互动率。 |
| **生日邀约** | 提前祝福会员生日快乐，并为其提供专属福利。 |

#### 提前准备非常重要

- **新品邀约**：
	- 在激活前需要查阅会员的基本信息资料，充分了解会员的需求。
	- 确保向会员推荐的新品符合其喜好，提高成交率。
- **活动邀约**：
	- 根据会员的喜好、历史消费记录等信息，邀请其参与相关活动。
	- 活动邀约要有针对性，确保信息与会员需求匹配。
- **生日邀约**：
	- 提前在会员生日当天发送祝福，并附带生日专属福利。
	- 生日邀约不仅增加会员的好感度，还能通过专属福利提高会员回店率。

#### 提醒：

- 生日专属福利可作为新品推荐的重要推手，提高邀约的成功率。
