# 操作系统

## 当前理解

操作系统的核心是隔离与调度：用户态/内核态靠 mode bit 和中断切换，系统调用是唯一入口；进程（PCB）、线程、上下文切换、IPC、ABI 构成执行模型；图形显示（X11/Wayland、桌面环境）和设备也都经过内核。
