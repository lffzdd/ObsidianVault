# IO与并发

## 当前理解

阻塞不是 CPU 卡住，而是进程被挂起等待；select/epoll 是“一次等多个 fd”的就绪通知，和同步/异步是两回事；配合非阻塞读取和事件驱动，才形成高并发 IO 模型（epoll 的水平与边缘触发）。
