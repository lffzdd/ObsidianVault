# 芯片开机

## 当前理解

瑞芯微芯片开机链：BootROM 固化在芯片里，从 SPI Flash / SD 卡加载 TPL+SPL，再加载 U-Boot，最后进入 boot 和 rootfs 分区；BootROM 只是跳板，系统并不是“通过它写进设备”的。
