# 计算机组成与硬件

## 当前理解

“从零造计算机”的路线：半导体（PN 结、二极管、三极管、MOSFET）→ 逻辑门 → 布尔计算组合出加法器 → 锁存器/触发器存状态 → 寄存器、内存 → 控制单元按时钟译码执行指令，组成 CPU，再到设备交互和屏幕输出。
