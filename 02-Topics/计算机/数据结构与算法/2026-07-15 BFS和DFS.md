# BFS
**BFS（Breadth-First Search，广度优先搜索）**是一种用于遍历或搜索树或图的算法。

它的核心思想是：**从初始节点开始，先访问其所有邻近的节点，然后再按照顺序访问邻近节点的邻近节点，以此类推，层层向外扩展。**

这就像在水中投下一枚石子，波纹一圈一圈向外扩散一样。

---

### 1. BFS 的核心特点与工作原理

BFS 依赖 **队列（Queue）** 这一数据结构来实现“先入先出”（FIFO）的遍历顺序。同时，为了防止在图的遍历中陷入死循环（循环依赖），通常需要一个 **已访问集合（Visited Set/Array）** 来记录已经遍历过的节点。

#### 算法基本步骤：
1. 将起点（根节点）放入队列，并标记为已访问。
2. 当队列不为空时，循环执行以下操作：
   - 从队列中弹出一个节点。
   - 处理该节点（例如打印、判断是否为目标节点等）。
   - 遍历该节点的所有未被访问的邻居节点：
     - 将邻居节点标记为已访问。
     - 将邻居节点放入队列。
3. 队列为空时，遍历结束。

---

### 2. 经典代码示例（Python 语言）

以下是使用 Python 实现图的 BFS 遍历的经典模板：

```python
from collections import deque

def bfs(graph, start):
    # 使用双端队列 deque 实现高效的队列操作
    queue = deque([start])
    # 记录已访问的节点，防止重复访问
    visited = {start}
    
    while queue:
        # 从队列左侧（队头）弹出一个节点
        node = queue.popleft()
        print(node, end=" ")  # 访问该节点
        
        # 遍历当前节点的所有邻居
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)  # 将未访问的邻居加入队列（队尾）

# 示例图（用邻接表表示）
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}

print("BFS 遍历顺序:")
bfs(graph, 'A')  # 输出可能是: A B C D E F
```

---

### 3. 复杂度分析

假设图有 $V$ 个顶点（Vertices），$E$ 条边（Edges）：
- **时间复杂度**：$\mathcal{O}(V + E)$。每个顶点都会入队和出队一次，每条边都会被检查一次。
- **空间复杂度**：$\mathcal{O}(V)$。在最坏的情况下（比如星状拓扑结构），队列中可能需要同时保存几乎所有的节点；同时 `visited` 集合也需要存储 $V$ 个节点。

---

### 4. 常见应用场景

BFS 因为其“层层扩展”的特性，非常适合解决以下问题：

1. **无权图的最短路径**：
   在边权全部相等的图（或无权图）中，BFS 第一次到达某个目标节点时，所经过的路径一定是最短路径（即步数最少）。
2. **树的层序遍历（Level Order Traversal）**：
   比如二叉树的按层打印（LeetCode 102）。
3. **连通分量与泛洪填充（Flood Fill）**：
   例如图像处理中的“油漆桶”工具（填充相同颜色的区域）、寻找网格图中的陆地/岛屿数量（LeetCode 200）。
4. **拓扑排序（Kahn 算法）**：
   在有向无环图（DAG）中，利用入度为 0 的节点入队来做拓扑排序。

# DFS

在带权图（即每条边都有不同的距离/权重）中，标准的 BFS 就不再适用了。因为 BFS 默认“步数越少距离越短”，但在带权图中，走 2 步的距离（比如 $10 + 10 = 20$）可能会比走 3 步（比如 $1 + 1 + 1 = 3$）要长得多。

为了实现**带距离（带权重）的最短路径**，最经典的算法是 **Dijkstra（迪杰斯特拉）算法**。

你可以把 Dijkstra 算法理解为**“带优先队列（最小堆）的 BFS”**。

---

### 1. Dijkstra 算法（单源最短路径，权重为正）

Dijkstra 算法的基本思想是：每次从尚未确定最短路径的节点中，挑选一个**当前累积距离最短**的节点，以此节点为媒介去更新（松弛）它邻居节点的距离。

#### 核心步骤：
1. 初始化：起点到自己的距离为 `0`，到其他所有节点的距离为 `无穷大 (∞)`。
2. 将所有节点放入一个优先队列（按当前已知最短距离排序）。
3. 循环执行：
   - 从优先队列中取出**当前累积距离最小**的节点 $u$。这个节点的距离此时已经确定，是最终的最短路径。
   - 遍历节点 $u$ 的所有邻居 $v$：
     - 如果 `起点到 u 的距离 + u 到 v 的边权 < 起点到 v 的当前已知距离`：
       - 更新 $v$ 的最短距离。
       - 将更新后的 $v$ 重新（或新）放入优先队列。
4. 队列为空或所有节点的最短路径都已确定时结束。

---

### 2. Python 代码实现（使用最小堆 `heapq`）

在实际编写中，我们常用 Python 内置的 `heapq` 模块来高效获取当前距离最小的节点。

```python
import heapq

def dijkstra(graph, start):
    # 记录起点到每个节点的最短距离，初始化为无穷大
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    
    # 优先队列，元素格式为 (距离, 节点)
    # Python 的 heapq 默认是最小堆，会根据元组的第一个元素（距离）进行排序
    priority_queue = [(0, start)]
    
    while priority_queue:
        # 取出当前累积距离最小的节点
        current_distance, current_node = heapq.heappop(priority_queue)
        
        # 【关键优化】如果弹出的距离大于当前记录的距离，说明这是一个过时的失效路径，直接跳过
        if current_distance > distances[current_node]:
            continue
            
        # 遍历当前节点的所有邻居
        # 邻居格式为: (neighbor_node, weight)
        for neighbor, weight in graph[current_node]:
            distance = current_distance + weight
            
            # 如果找到了更短的路径，则更新并放入优先队列
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))
                
    return distances

# 示例带权图（邻接表表示）
# 结构：A -(4)-> B, A -(2)-> C, C -(1)-> B, B -(3)-> D, C -(5)-> D
graph = {
    'A': [('B', 4), ('C', 2)],
    'B': [('D', 3)],
    'C': [('B', 1), ('D', 5)],
    'D': []
}

distances = dijkstra(graph, 'A')
print("从 A 到各个节点的最短距离:", distances)
# 输出: {'A': 0, 'B': 3, 'C': 2, 'D': 6}
# 解释：A -> B 的最短路径是 A -> C -> B (距离为 2+1=3)，而不是直接 A -> B (距离为 4)
```

**复杂度**：
- **时间复杂度**：$\mathcal{O}((V + E) \log V)$。每次从堆中取出和插入元素需要 $\mathcal{O}(\log V)$ 时间。
- **空间复杂度**：$\mathcal{O}(V + E)$。

---

### 3. 其他带权最短路径算法（根据不同场景选择）

虽然 Dijkstra 是最常用的算法，但在一些特殊场景下，我们需要使用其他算法：

#### A. 存在负权重边 —— **Bellman-Ford 算法 / SPFA**
*   **问题**：如果图中含有**负权重边**，Dijkstra 会失效（因为它的贪心策略建立在“路径只会变长，不会变短”的假设上）。
*   **解决**：使用 **Bellman-Ford 算法**。它通过对所有边进行 $V-1$ 次“松弛”操作来计算最短路径，并且可以检测图中是否存在**负权环**（如果存在负权环，最短路径会无限变小，无解）。
*   **时间复杂度**：$\mathcal{O}(V \times E)$。

#### B. 多源最短路径（计算任意两点之间的最短距离） —— **Floyd-Warshall 算法**
*   **问题**：如果我们需要求图中**任意两个节点**之间的最短距离，而不是单单从某一个起点出发。
*   **解决**：使用基于动态规划的 **Floyd-Warshall 算法**。通过三重循环，逐步引入中间节点来更新任意两点间的距离。
*   **时间复杂度**：$\mathcal{O}(V^3)$。

---

### 总结：如何选择最短路径算法？

1. **无权图** $\rightarrow$ 用 **BFS** （最简单，时间 $\mathcal{O}(V+E)$）。
2. **带权图（无负权边）** $\rightarrow$ 用 **Dijkstra** （最经典高效，时间 $\mathcal{O}((V+E)\log V)$）。
3. **带权图（含负权边）** $\rightarrow$ 用 **Bellman-Ford** 或 **SPFA**。
4. **求任意两点间距离** $\rightarrow$ 用 **Floyd-Warshall**。
