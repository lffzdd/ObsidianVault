## 什么是工厂方法？

**工厂方法**就是一个**专门用来创建对象的方法**，它提供了除了 [__init__](cci:1://file:///f:/Projects/llm/src/Transformer/vocab.py:22:4-28:34) 之外的**其他方式**来创建实例。

就像工厂生产产品一样，工厂方法"生产"对象实例。

---

## 为什么需要工厂方法？

### 问题：[__init__](cci:1://file:///f:/Projects/llm/src/Transformer/vocab.py:22:4-28:34) 的局限性

[__init__](cci:1://file:///f:/Projects/llm/src/Transformer/vocab.py:22:4-28:34) 只能有一种初始化方式：

```python
class Vocab:
    def __init__(self):
        self.token_to_id = {"<PAD>": 0, "<UNK>": 1}
        self.id_to_token = {0: "<PAD>", 1: "<UNK>"}
```

但实际使用中，我们可能需要**多种创建方式**：

1. **从空白创建**：[Vocab()](cci:2://file:///f:/Projects/llm/src/my_transformer/_1_tokenizer.py:169:0-228:20)
2. **从文件加载**：需要读取文件
3. **从字典创建**：已有现成的数据
4. **从列表创建**：给定 token 列表

如果只用 [__init__](cci:1://file:///f:/Projects/llm/src/Transformer/vocab.py:22:4-28:34)，代码会很复杂：

```python
# ❌ 不好的做法：把所有逻辑塞进 __init__
class Vocab:
    def __init__(self, from_file=None, from_dict=None, from_list=None):
        if from_file:
            # 从文件加载
            ...
        elif from_dict:
            # 从字典创建
            ...
        elif from_list:
            # 从列表创建
            ...
        else:
            # 默认创建
            ...
```

这样代码**难读、难维护、容易出错**。

---

## 工厂方法的解决方案

使用**多个工厂方法**，每个方法负责一种创建方式：

```python
class Vocab:
    def __init__(self):
        """默认构造函数：创建空词表"""
        self.token_to_id = {"<PAD>": 0, "<UNK>": 1}
        self.id_to_token = {0: "<PAD>", 1: "<UNK>"}
    
    @classmethod
    def from_file(cls, path: str):
        """工厂方法 1：从文件创建"""
        vocab = cls()
        vocab.load(path)
        return vocab
    
    @classmethod
    def from_dict(cls, data: dict):
        """工厂方法 2：从字典创建"""
        vocab = cls()
        vocab.token_to_id = data
        vocab.id_to_token = {v: k for k, v in data.items()}
        return vocab
    
    @classmethod
    def from_tokens(cls, tokens: list[str]):
        """工厂方法 3：从 token 列表创建"""
        vocab = cls()
        for token in tokens:
            vocab.add_tokens(token)
        return vocab
```

## 使用示例

现在创建对象变得**清晰、直观**：

```python
# 方式 1：创建空词表
vocab1 = Vocab()

# 方式 2：从文件加载
vocab2 = Vocab.from_file("vocab.json")

# 方式 3：从字典创建
vocab3 = Vocab.from_dict({"hello": 4, "world": 5})

# 方式 4：从 token 列表创建
vocab4 = Vocab.from_tokens(["hello", "world", "python"])
```

每种方式**语义清晰**，一看就知道在做什么！

## 真实世界的例子

### 1. **Python 内置的工厂方法**

```python
# datetime 类的工厂方法
from datetime import datetime

# 默认构造
dt1 = datetime(2026, 1, 3, 15, 0, 0)

# 工厂方法：从当前时间创建
dt2 = datetime.now()

# 工厂方法：从时间戳创建
dt3 = datetime.fromtimestamp(1735891200)

# 工厂方法：从字符串创建
dt4 = datetime.fromisoformat("2026-01-03T15:00:00")
```

## 工厂方法的优点

| 优点 | 说明 | 示例 |
|------|------|------|
| **语义清晰** | 方法名说明了创建方式 | [from_file](cci:1://file:///f:/Projects/llm/src/my_transformer/_1_tokenizer.py:224:4-228:20) 一看就知道从文件加载 |
| **灵活性** | 可以有多种创建方式 | [from_file](cci:1://file:///f:/Projects/llm/src/my_transformer/_1_tokenizer.py:224:4-228:20), `from_dict`, `from_tokens` |
| **封装复杂逻辑** | 隐藏创建细节 | 用户不需要知道如何解析文件 |
| **支持继承** | 子类自动继承工厂方法 | 使用 `cls()` 而不是 [Vocab()](cci:2://file:///f:/Projects/llm/src/my_transformer/_1_tokenizer.py:169:0-228:20) |
| **代码可读性** | 比复杂的 [__init__](cci:1://file:///f:/Projects/llm/src/Transformer/vocab.py:22:4-28:34) 更易读 | 每个方法职责单一 |

## 工厂方法 vs 普通构造函数

```python
# ❌ 不使用工厂方法：需要两步，容易忘记第二步
vocab = Vocab()
vocab.load("vocab.json")  # 容易忘记调用

# ✅ 使用工厂方法：一步完成，不会出错
vocab = Vocab.from_file("vocab.json")
```

## 总结

**工厂方法** = **专门用来创建对象的类方法**

它的核心思想是：
- 提供**多种创建对象的方式**
- 让代码**更清晰、更易用**
- **封装复杂的初始化逻辑**

就像你去餐厅点餐：
- [__init__()](cci:1://file:///f:/Projects/llm/src/Transformer/vocab.py:22:4-28:34) = 自己买食材做饭
- [from_file()](cci:1://file:///f:/Projects/llm/src/my_transformer/_1_tokenizer.py:224:4-228:20) = 点外卖（从文件加载）
- `from_dict()` = 点套餐（从字典创建）
- `from_tokens()` = 点单品（从列表创建）

每种方式都能得到一顿饭（对象），但方式不同，使用场景也不同！🍽️
