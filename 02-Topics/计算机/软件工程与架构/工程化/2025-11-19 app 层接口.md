# ✔ **① 构建 app 层（API 层）——你目前整个项目缺少的部分**

```
project/
```

# ✔ **② 统一 API 返回结构**

你现在的 send 返回：

```python
{
  "trade_no": "...",
  "ok": True/False,
  "stage": "...",
  "error": "...",
  "coupon_no": ...
}
```

这是非常好的“内层结构”。

但对外暴露给前端，应该再套一层统一格式，例如：

```json
{
  "success": true,
  "data": [...],
  "message": null
```

```json

  "success": false,
  "data": [],
  "message": "数据库连接失败"
}
```

你的服务的“外壳格式”需要统一一下。

# ✔ **③ API 层只负责：**

- 接受 HTTP 请求
- 调 core.services 对应函数
- 包装统一 JSON 格式
- 捕获异常（防止服务挂掉）
- 不写任何业务逻辑

你现在的服务逻辑已经非常干净，写 app 层会非常简单。

# 🎁 我先给你一份“可直接粘贴”的 Flask 版本 app.py

你可以立即用：

```python
from flask import Flask, request, jsonify
from core.services import preview_unissued_orders, send_coupon_for_order

app = Flask(__name__)


def make_response(success: bool, data=None, message=None):
    return jsonify({
        "success": success,
        "data": data,
        "message": message
    })


@app.get("/preview")
def preview():
    try:
        previews = preview_unissued_orders()
        return make_response(True, previews)
    except Exception as e:
        return make_response(False, None, f"预览失败: {str(e)}")


@app.post("/send")
def send():
    body = request.json
    trade_nos = body.get("trade_nos")

    if not trade_nos:
        return make_response(False, None, "trade_nos 不能为空")

    try:
        results = send_coupon_for_order(trade_nos)
        return make_response(True, results)
    except Exception as e:
        return make_response(False, None, f"发券失败: {str(e)}")


if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

你会看到：

- app 层完全不写逻辑
- 所有业务由 core 来负责
- 所有 IO 和外部接口由 base 层负责
- 所有返回统一 JSON 格式
- 所有异常都 catch，不会崩溃

这就是典型的：

> “壳负责接收请求与输出，核负责业务逻辑，底层负责 IO”

你现在的分层正好可以完美落到这个结构上。

---

# ✔ **④ main.py 改成负责启动 app，而不是跑核心逻辑**

例如：

```python
from app.app import app

if __name__ == "__main__":
    app.run()
```

或者：

```python
# main.py
from app.app import app

# nothing else
```

这样 main.py 不再带有业务逻辑，不会影响你的 package 上下文。
