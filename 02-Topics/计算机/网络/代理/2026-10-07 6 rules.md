# 
很好，我们现在正式拼上 Clash 配置文件中的最后一块大拼图，也是最庞大的分流地图——`rules`（分流规则）。

在配置文件中，`rules:` 模块就像是交警在十字路口贴出的“车辆分流告示”。

当你的浏览器发出了一个请求（比如你想访问百度，或者想访问 YouTube），Clash 就会拿着这个请求的特征，从上到下一行一行地去对地图。一旦对上了哪一行，流量就会立刻被送往那一行指定的“特种部队（策略组）”。

我们先来看几行最经典、最标准的规则长相：

---

## 第一步：`rules` 的基本长相与格式

在配置文件的最底部，它通常长这样（注意，因为是一条条并列的规则清单，所以每一行开头都带着我们刚学过的减号 `-`）：

```yaml
rules:
  - DOMAIN-SUFFIX,google.com,🚀 节点选择
  - DOMAIN-KEYWORD,bilibili,🎬 哔哩哔哩
  - GEOIP,CN,DIRECT
  - MATCH,🚀 节点选择
```

每一个规则大礼包，都用逗号 `,` 严格切成了三部分。它的标准公式是：  
👉 `- 匹配类型, 匹配内容, 要去的策略组/节点`

我们先把最常用的几种“匹配类型”拆开，看看它们都是怎么抓取域名的：

## 1. `DOMAIN-SUFFIX`（域名后缀匹配）

- 通俗解释：“认祖归宗”法。
- 例子：`- DOMAIN-SUFFIX,google.com,🚀 节点选择`
- 怎么工作：只要你访问的网址是以 `google.com` 结尾的（比如 `://google.com`、`://google.com`、`://google.com`），全部算作命中。Clash 会立刻把这些流量打包，丢给你叫 `🚀 节点选择` 的那个策略组。

## 2. `DOMAIN-KEYWORD`（域名关键字匹配）

- 通俗解释：“字形辨认”法。
- 例子：`- DOMAIN-KEYWORD,bilibili,🎬 哔哩哔哩`
- 怎么工作：不管网址多长、后缀是什么，只要里面包含了 `bilibili` 这几个字母（比如 `bilibili.com`、`bilibili.tv`，甚至随便一个奇奇怪怪的广告链接 `ads-bilibili-test.com`），都会被揪出来，强制送往 `🎬 哔哩哔哩` 策略组。

---

这两种是基于“域名（网址）”的最直接判断。

好的，那我们继续往下推進，看看 Clash 是如何通过“地理位置（IP 地址）”来进行判断，以及它是如何进行完美收尾的。

在规则列表中，接下来出场的就是两个极其威猛的“范围型”武器：

```yaml
rules:
  ...
  - GEOIP,CN,DIRECT
  - MATCH,🚀 节点选择
```

---

## 3. `GEOIP,CN,DIRECT`（地理位置 IP 匹配）

- 它是干嘛的：“看户口本分流”法。
- 怎么工作：
    
    - 当一个请求来到 Clash 时，如果它上面的那些 `DOMAIN`（域名）规则全都没有对上，Clash 就会启动前面学到的 DNS 机制，去查出这个网站的真实 IP 地址。
    - 查到 IP 后，Clash 会翻开本地的一张庞大的“全球 IP 分布图”（通常叫 `geoip.dat` 数据库）。
    - 如果发现这个 IP 的注册地属于 `CN`（中国大陆），Clash 就会瞬间判定：这是国内服务！于是流量直接走 `DIRECT`（直连，不翻墙），确保你刷国内 App 时能跑满家里的百兆/千兆宽带。
    

---

## 4. `MATCH,🚀 节点选择`（终极兜底）

- 它是干嘛的：“天罗地网”终极保底规则。
- 规矩：它必须放在整个 `rules:` 列表的最底下一行。
- 怎么工作：
    
    - Clash 的规则是从第一行开始，像下楼梯一样从上到下一行行往下对的。
    - 如果你访问了一个非常冷门的国外小众网站，上面的域名规则没写它，它也不是中国的 IP，那么这个请求就会一直一路滑到最底部。
    - 最后，它会一头撞在 `MATCH` 上。`MATCH` 在英文里是“匹配/符合”的意思，但在 Clash 里它代表 “100% 绝对命中”。
    - 不管是什么流量，只要能走到这一行，全部听从 `MATCH` 的指挥。这里写着去 `🚀 节点选择`，它就会被强制送去走代理。这样可以确保任何没有被规则照顾到的国外新网站，也绝对不会漏网，保证你能正常打开。
    

---

## 🚦 一个至关重要的“排队规矩”

听完这些规则，你可能会问：如果一个规则写着去直连，另一个写着去代理，Clash 听谁的？  
答案是：谁在上面听谁的（先到先得）！

举个例子：

```yaml
rules:
  - DOMAIN-KEYWORD,google,🚀 节点选择 # 1号交警：带 google 的去代理
  - DOMAIN-SUFFIX,com,DIRECT         # 2号交警：.com 结尾的去直连
```

当你访问 `google.com` 时：

1. 它先碰到 1 号交警，含有关键字 `google`，成功命中！ 流量立刻被送去代理，后面的规则直接作废。
2. 即使它也符合 2 号交警（以 `.com` 结尾），但它根本没有机会走到第二行了。

所以，写规则的秘诀通常是：越具体的、范围越小的（比如单个域名）写在最上面；越模糊的、范围越大的（比如 GEOIP、MATCH）写在最下面。
