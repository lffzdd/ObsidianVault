# 浏览器

## 当前理解

浏览器是多进程系统：主进程管理、渲染进程跑 Blink 和 JS 引擎（事件循环），通过 GPU 合成上屏；WebSocket 和网关负责实时通信；浏览器指纹来自这些底层差异。
