### **从零构建一个编译器：用 Python 实现一门迷你语言 MiniLang，覆盖词法、语法、语义到代码生成的完整链路**

学习编译器最有效的方法不是先啃《龙书》，而是亲手写一个能跑起来的小编译器，再回头补理论。下面我会带你一步步实现一门叫做 **MiniLang** 的极简语言，它支持变量、算术、比较、`if/else`、`while` 循环和 `print` 语句，最终编译成一种自定义的栈式虚拟机字节码并执行。每一步都会先讲清楚"为什么这么做"，再给出完整可运行的代码，你只需要一个 Python 3.8+ 环境就能跟着做。

---

## **第 0 步：编译器到底在做什么**

编译器的本质是一次**结构化的翻译**：把人写的源代码（字符串）翻译成机器能执行的形式（字节码、汇编、机器码或另一种高级语言）。这个翻译过程通常被拆成几个阶段，每一阶段都把上一阶段的输出"提升"到一个更结构化的表示：

源代码（字符串） → **词法分析（Lexer）** → Token 流 → **语法分析（Parser）** → 抽象语法树 AST → **语义分析（Semantic Analysis）** → 带类型/作用域信息的 AST → **代码生成（CodeGen）** → 目标代码 → **执行（VM 或 CPU）**。

我们要实现的 MiniLang 长这样：

```
let x = 10;
let y = 0;
while (x > 0) {
    y = y + x;
    x = x - 1;
}
print y;
```

这段代码应该输出 `55`。围绕它，我们会写大约 400 行 Python，把上面五个阶段全部实现一遍。

---

## **第 1 步：词法分析器（Lexer）—— 把字符流变成 Token 流**

### **为什么需要词法分析**

直接对字符串做语法分析非常痛苦，因为你既要处理空格、注释，又要识别 `let`、`while` 这种关键字，还要区分 `==` 和 `=`。词法分析器（也叫 Scanner、Tokenizer）的任务就是把字符流切成一个个有意义的最小单元——**Token**，比如 `LET`、`IDENT("x")`、`NUMBER(10)`、`SEMI`。这一步之后，后面的解析器就只需要面对一串规整的 Token，不用再操心空白和字符细节。

### **设计 Token 类型**

MiniLang 需要的 Token 大致分四类：关键字（`let`、`if`、`else`、`while`、`print`）、标识符与字面量（变量名、整数）、运算符（`+ - * / == != < > <= >= =`）、分隔符（`( ) { } ;`）。我们用一个枚举来统一管理：

```python
from enum import Enum, auto
from dataclasses import dataclass
from typing import Any, List

class TT(Enum):
    # 字面量与标识符
    NUMBER = auto(); IDENT = auto()
    # 关键字
    LET = auto(); IF = auto(); ELSE = auto(); WHILE = auto(); PRINT = auto()
    # 运算符
    PLUS = auto(); MINUS = auto(); STAR = auto(); SLASH = auto()
    ASSIGN = auto(); EQ = auto(); NEQ = auto()
    LT = auto(); GT = auto(); LE = auto(); GE = auto()
    # 分隔符
    LPAREN = auto(); RPAREN = auto(); LBRACE = auto(); RBRACE = auto(); SEMI = auto()
    EOF = auto()

@dataclass
class Token:
    type: TT
    value: Any
    line: int
```

### **手写 Lexer 的核心循环**

实现思路非常朴素：维护一个游标 `pos`，每次根据当前字符决定走哪个分支——是数字就一直读到非数字为止，是字母就读完整个标识符再判断是不是关键字，是符号就尝试匹配双字符运算符（如 `==`）再退而求其次匹配单字符。

```python
KEYWORDS = {
    "let": TT.LET, "if": TT.IF, "else": TT.ELSE,
    "while": TT.WHILE, "print": TT.PRINT,
}

class Lexer:
    def __init__(self, src: str):
        self.src = src
        self.pos = 0
        self.line = 1

    def _peek(self, offset=0):
        p = self.pos + offset
        return self.src[p] if p < len(self.src) else ""

    def _advance(self):
        ch = self.src[self.pos]; self.pos += 1
        if ch == "\n": self.line += 1
        return ch

    def tokenize(self) -> List[Token]:
        tokens = []
        while self.pos < len(self.src):
            ch = self._peek()
            if ch.isspace():
                self._advance(); continue
            if ch.isdigit():
                start = self.pos
                while self._peek().isdigit(): self._advance()
                tokens.append(Token(TT.NUMBER, int(self.src[start:self.pos]), self.line))
                continue
            if ch.isalpha() or ch == "_":
                start = self.pos
                while self._peek().isalnum() or self._peek() == "_": self._advance()
                word = self.src[start:self.pos]
                tt = KEYWORDS.get(word, TT.IDENT)
                tokens.append(Token(tt, word, self.line))
                continue
            # 双字符运算符优先
            two = ch + self._peek(1)
            mapping2 = {"==": TT.EQ, "!=": TT.NEQ, "<=": TT.LE, ">=": TT.GE}
            if two in mapping2:
                self._advance(); self._advance()
                tokens.append(Token(mapping2[two], two, self.line)); continue
            mapping1 = {
                "+": TT.PLUS, "-": TT.MINUS, "*": TT.STAR, "/": TT.SLASH,
                "=": TT.ASSIGN, "<": TT.LT, ">": TT.GT,
                "(": TT.LPAREN, ")": TT.RPAREN,
                "{": TT.LBRACE, "}": TT.RBRACE, ";": TT.SEMI,
            }
            if ch in mapping1:
                self._advance()
                tokens.append(Token(mapping1[ch], ch, self.line)); continue
            raise SyntaxError(f"非法字符 {ch!r} 在第 {self.line} 行")
        tokens.append(Token(TT.EOF, None, self.line))
        return tokens
```

这里有两个值得记住的小技巧：**关键字其实是"特殊的标识符"**，所以先按标识符规则读完，再查表看是不是关键字；**多字符运算符必须先于单字符匹配**，否则 `==` 会被错切成两个 `=`。

## **第 2 步：语法分析器（Parser）—— 把 Token 流变成 AST**

### **从语法规则到代码：递归下降**

我们用 **EBNF** 描述 MiniLang 的语法，这一步是整个编译器最值得花时间想清楚的地方：

```
program    := statement*
statement  := letStmt | assignStmt | ifStmt | whileStmt | printStmt | block
letStmt    := "let" IDENT "=" expr ";"
assignStmt := IDENT "=" expr ";"
ifStmt     := "if" "(" expr ")" block ("else" block)?
whileStmt  := "while" "(" expr ")" block
printStmt  := "print" expr ";"
block      := "{" statement* "}"

expr       := comparison
comparison := addsub (("=="|"!="|"<"|">"|"<="|">=") addsub)*
addsub     := muldiv (("+"|"-") muldiv)*
muldiv     := unary (("*"|"/") unary)*
unary      := "-" unary | primary
primary    := NUMBER | IDENT | "(" expr ")"
```

注意表达式的写法是**按优先级分层**：越靠下优先级越高，于是 `1 + 2 * 3` 会被解析成 `1 + (2*3)`，因为 `addsub` 调用 `muldiv` 时，乘除已经先把 `2*3` 吃掉了。这种"每个优先级一个函数"的写法叫**递归下降**，它和 EBNF 几乎是一一对应的，非常容易写也容易调。

### **定义 AST 节点**

AST（抽象语法树）是源程序的结构化表示，它去掉了括号、分号等"形式"信息，只保留"含义"。我们用 dataclass 定义节点：

```python
from dataclasses import dataclass, field
from typing import List, Optional, Union

@dataclass
class Num:        value: int
@dataclass
class Var:        name: str
@dataclass
class BinOp:      op: str; left: "Expr"; right: "Expr"
@dataclass
class UnaryOp:    op: str; operand: "Expr"
Expr = Union[Num, Var, BinOp, UnaryOp]

@dataclass
class Let:        name: str; expr: Expr
@dataclass
class Assign:     name: str; expr: Expr
@dataclass
class Print:      expr: Expr
@dataclass
class If:         cond: Expr; then_block: List["Stmt"]; else_block: Optional[List["Stmt"]]
@dataclass
class While:      cond: Expr; body: List["Stmt"]
Stmt = Union[Let, Assign, Print, If, While]

@dataclass
class Program:    stmts: List[Stmt] = field(default_factory=list)
```

> 上面 dataclass 的紧凑写法只是为了节省篇幅，实际项目里建议每个字段单独一行。

### **递归下降 Parser 实现**

```python
class Parser:
    def __init__(self, tokens: List[Token]):
        self.tokens = tokens; self.pos = 0

    def _peek(self, offset=0): return self.tokens[self.pos + offset]
    def _eat(self, tt: TT):
        tok = self._peek()
        if tok.type != tt:
            raise SyntaxError(f"期望 {tt}，但在第 {tok.line} 行得到 {tok.type}({tok.value})")
        self.pos += 1
        return tok
    def _match(self, *tts):
        if self._peek().type in tts:
            self.pos += 1
            return self.tokens[self.pos - 1]
        return None

    # —— 语句 ——
    def parse_program(self) -> Program:
        prog = Program()
        while self._peek().type != TT.EOF:
            prog.stmts.append(self.parse_stmt())
        return prog

    def parse_stmt(self) -> Stmt:
        t = self._peek().type
        if t == TT.LET:    return self.parse_let()
        if t == TT.IF:     return self.parse_if()
        if t == TT.WHILE:  return self.parse_while()
        if t == TT.PRINT:  return self.parse_print()
        if t == TT.IDENT:  return self.parse_assign()
        raise SyntaxError(f"未知语句开头：{self._peek()}")

    def parse_let(self):
        self._eat(TT.LET); name = self._eat(TT.IDENT).value
        self._eat(TT.ASSIGN); expr = self.parse_expr(); self._eat(TT.SEMI)
        return Let(name, expr)

    def parse_assign(self):
        name = self._eat(TT.IDENT).value
        self._eat(TT.ASSIGN); expr = self.parse_expr(); self._eat(TT.SEMI)
        return Assign(name, expr)

    def parse_print(self):
        self._eat(TT.PRINT); expr = self.parse_expr(); self._eat(TT.SEMI)
        return Print(expr)

    def parse_block(self):
        self._eat(TT.LBRACE); stmts = []
        while self._peek().type != TT.RBRACE:
            stmts.append(self.parse_stmt())
        self._eat(TT.RBRACE); return stmts

    def parse_if(self):
        self._eat(TT.IF); self._eat(TT.LPAREN)
        cond = self.parse_expr(); self._eat(TT.RPAREN)
        then_b = self.parse_block(); else_b = None
        if self._match(TT.ELSE): else_b = self.parse_block()
        return If(cond, then_b, else_b)

    def parse_while(self):
        self._eat(TT.WHILE); self._eat(TT.LPAREN)
        cond = self.parse_expr(); self._eat(TT.RPAREN)
        body = self.parse_block(); return While(cond, body)

    # —— 表达式（优先级从低到高）——
    def parse_expr(self): return self.parse_comparison()

    def parse_comparison(self):
        left = self.parse_addsub()
        while self._peek().type in (TT.EQ, TT.NEQ, TT.LT, TT.GT, TT.LE, TT.GE):
            op = self._eat(self._peek().type).value
            right = self.parse_addsub()
            left = BinOp(op, left, right)
        return left

    def parse_addsub(self):
        left = self.parse_muldiv()
        while self._peek().type in (TT.PLUS, TT.MINUS):
            op = self._eat(self._peek().type).value
            right = self.parse_muldiv()
            left = BinOp(op, left, right)
        return left

    def parse_muldiv(self):
        left = self.parse_unary()
        while self._peek().type in (TT.STAR, TT.SLASH):
            op = self._eat(self._peek().type).value
            right = self.parse_unary()
            left = BinOp(op, left, right)
        return left

    def parse_unary(self):
        if self._match(TT.MINUS):
            return UnaryOp("-", self.parse_unary())
        return self.parse_primary()

    def parse_primary(self):
        tok = self._peek()
        if tok.type == TT.NUMBER:
            self._eat(TT.NUMBER); return Num(tok.value)
        if tok.type == TT.IDENT:
            self._eat(TT.IDENT); return Var(tok.value)
        if tok.type == TT.LPAREN:
            self._eat(TT.LPAREN); e = self.parse_expr(); self._eat(TT.RPAREN); return e
        raise SyntaxError(f"非法表达式：{tok}")
```

写完之后建议把 AST 打印出来看看，比如 `1 + 2 * 3` 应该是 `BinOp('+', Num(1), BinOp('*', Num(2), Num(3)))`，乘法天然嵌在加法里——这就是优先级在树形结构上的体现。

## **第 3 步：语义分析（Semantic Analysis）—— 检查"语法对，但意义不对"的错误**

语法分析只检查"长得对不对"，但 `let x = y;` 在 `y` 从未声明时，语法是对的，语义却是错的。我们需要做一次 AST 遍历，建立**符号表**，发现下面两类问题：使用未声明的变量、重复声明同一个变量。

```python
class Resolver:
    def __init__(self): self.scope = set()

    def resolve(self, prog: Program):
        for s in prog.stmts: self._stmt(s)

    def _stmt(self, s):
        if isinstance(s, Let):
            if s.name in self.scope:
                raise NameError(f"变量 {s.name} 重复声明")
            self._expr(s.expr)        # 注意：先检查右边表达式
            self.scope.add(s.name)
        elif isinstance(s, Assign):
            if s.name not in self.scope:
                raise NameError(f"变量 {s.name} 未声明")
            self._expr(s.expr)
        elif isinstance(s, Print):
            self._expr(s.expr)
        elif isinstance(s, If):
            self._expr(s.cond)
            for x in s.then_block: self._stmt(x)
            if s.else_block:
                for x in s.else_block: self._stmt(x)
        elif isinstance(s, While):
            self._expr(s.cond)
            for x in s.body: self._stmt(x)

    def _expr(self, e):
        if isinstance(e, Num): return
        if isinstance(e, Var):
            if e.name not in self.scope:
                raise NameError(f"变量 {e.name} 未声明")
            return
        if isinstance(e, BinOp):
            self._expr(e.left); self._expr(e.right); return
        if isinstance(e, UnaryOp):
            self._expr(e.operand); return
```

这里有个细节：处理 `Let` 时**先解析右值再加入作用域**，这样 `let x = x + 1;` 就会被正确地报为未声明，而不是把左边的 `x` 当成已存在。真实的编译器在这一步还会做类型检查、常量折叠等优化，我们这里只做最小集合。

## **第 4 步：代码生成（CodeGen）—— 把 AST 编译为字节码**

### **目标：栈式虚拟机字节码**

我们设计一台极简的栈机，它只有一个"操作数栈"和一张"变量表"。指令集：

| 指令                 | 含义                   |
| -------------------- | ---------------------- |
| `PUSH n`             | 把整数 n 压栈          |
| `LOAD name`          | 读取变量 name 压栈     |
| `STORE name`         | 弹栈并存入变量 name    |
| `ADD/SUB/MUL/DIV`    | 弹两个值运算后压栈     |
| `EQ/NEQ/LT/GT/LE/GE` | 比较，结果 0/1 压栈    |
| `NEG`                | 取负                   |
| `PRINT`              | 弹栈打印               |
| `JMP addr`           | 无条件跳到 addr        |
| `JMP_IF_FALSE addr`  | 弹栈，若为 0 跳到 addr |
| `HALT`               | 停机                   |

之所以选栈式，是因为它**生成代码极其简单**：表达式按"后序遍历"翻译就行，左子树先压栈、右子树再压栈、最后执行运算指令把它们消费掉。Python 自身的字节码、JVM、WebAssembly 都是栈式的。

### **生成器实现：处理跳转回填**

最难的是 `if/while` 的跳转地址——生成 `JMP_IF_FALSE` 时我们还不知道要跳到哪里，因为目标地址在后面。解决办法是**先填一个占位 0，记下指令位置，等真正知道地址时回过头来改**，这叫"回填（backpatching）"。

```python
class CodeGen:
    def __init__(self):
        self.code: List[tuple] = []

    def emit(self, *instr) -> int:
        self.code.append(instr); return len(self.code) - 1

    def patch(self, idx: int, *instr):
        self.code[idx] = instr

    def gen(self, prog: Program):
        for s in prog.stmts: self._stmt(s)
        self.emit("HALT"); return self.code

    def _stmt(self, s):
        if isinstance(s, Let) or isinstance(s, Assign):
            self._expr(s.expr); self.emit("STORE", s.name)
        elif isinstance(s, Print):
            self._expr(s.expr); self.emit("PRINT")
        elif isinstance(s, If):
            self._expr(s.cond)
            jf = self.emit("JMP_IF_FALSE", 0)         # 占位
            for x in s.then_block: self._stmt(x)
            if s.else_block:
                jend = self.emit("JMP", 0)            # 占位
                self.patch(jf, "JMP_IF_FALSE", len(self.code))
                for x in s.else_block: self._stmt(x)
                self.patch(jend, "JMP", len(self.code))
            else:
                self.patch(jf, "JMP_IF_FALSE", len(self.code))
        elif isinstance(s, While):
            start = len(self.code)
            self._expr(s.cond)
            jf = self.emit("JMP_IF_FALSE", 0)
            for x in s.body: self._stmt(x)
            self.emit("JMP", start)                   # 回到循环头
            self.patch(jf, "JMP_IF_FALSE", len(self.code))

    def _expr(self, e):
        if isinstance(e, Num):  self.emit("PUSH", e.value); return
        if isinstance(e, Var):  self.emit("LOAD", e.name); return
        if isinstance(e, UnaryOp):
            self._expr(e.operand); self.emit("NEG"); return
        if isinstance(e, BinOp):
            self._expr(e.left); self._expr(e.right)
            op_map = {"+":"ADD","-":"SUB","*":"MUL","/":"DIV",
                      "==":"EQ","!=":"NEQ","<":"LT",">":"GT","<=":"LE",">=":"GE"}
            self.emit(op_map[e.op])
```

## **第 5 步：虚拟机（VM）—— 真正把字节码跑起来**

虚拟机的实现就是一个 `while` 大循环：取指、译码、执行、推进 PC。

```python
class VM:
    def __init__(self, code):
        self.code = code; self.pc = 0
        self.stack: List[int] = []; self.vars = {}

    def run(self):
        while True:
            instr = self.code[self.pc]; self.pc += 1
            op = instr[0]
            if op == "PUSH":   self.stack.append(instr[1])
            elif op == "LOAD": self.stack.append(self.vars[instr[1]])
            elif op == "STORE":self.vars[instr[1]] = self.stack.pop()
            elif op == "PRINT":print(self.stack.pop())
            elif op == "NEG":  self.stack.append(-self.stack.pop())
            elif op in ("ADD","SUB","MUL","DIV","EQ","NEQ","LT","GT","LE","GE"):
                b = self.stack.pop(); a = self.stack.pop()
                self.stack.append({
                    "ADD": a+b, "SUB": a-b, "MUL": a*b, "DIV": a//b,
                    "EQ": int(a==b), "NEQ": int(a!=b),
                    "LT": int(a<b), "GT": int(a>b),
                    "LE": int(a<=b), "GE": int(a>=b),
                }[op])
            elif op == "JMP":  self.pc = instr[1]
            elif op == "JMP_IF_FALSE":
                if self.stack.pop() == 0: self.pc = instr[1]
            elif op == "HALT": return
            else: raise RuntimeError(f"未知指令 {op}")
```

### **把所有零件串起来**

```python
src = """
let x = 10;
let y = 0;
while (x > 0) {
    y = y + x;
    x = x - 1;
}
print y;
"""

tokens = Lexer(src).tokenize()
ast = Parser(tokens).parse_program()
Resolver().resolve(ast)
code = CodeGen().gen(ast)
for i, ins in enumerate(code): print(i, ins)   # 看一眼字节码
VM(code).run()                                  # 输出 55
```

跑通后建议你做一件事：把 `print y;` 之前的程序改成 `let z = (1 + 2) * 3; print z;`，再观察生成的字节码——你会清楚地看到"先压 1、再压 2，ADD，再压 3，MUL，再 PRINT"，这就是栈机表达式求值的全部秘密。

## **第 6 步：之后该往哪儿走**

到这里你已经拥有一个完整的、五阶段俱全的小编译器。但它还很简陋，下面是几条自然延伸的方向，每一条都会让你对编译器的理解再深一层。

**给语言加功能**是最容易看到效果的：先加布尔类型与字符串、再加 `for` 循环、然后是函数（这会迫使你引入"调用栈帧""返回地址""局部作用域"），最后是数组、闭包、对象。每加一个特性，你都要回到 Lexer / Parser / Resolver / CodeGen / VM 五处依次改，这种"穿透感"是理解编译器架构的最佳方式。

**在中间加一层 IR（中间表示）**会让你触碰到现代编译器的核心思想。AST 直接生成字节码很方便，但优化做不动。如果先把 AST 翻译成"三地址码"或 SSA 形式，再做常量折叠、死代码消除、寄存器分配等优化，你会真正理解 LLVM 这类工业编译器为什么长成那个样子。

**用工具替换手写部分**则可以让你看到另一种工程取舍：用 [PLY](https://www.dabeaz.com/ply/)、[Lark](https://github.com/lark-parser/lark) 或 ANTLR 自动生成 Lexer/Parser，把精力集中到语义和优化上；或者反过来，把整个编译器用 Rust/C++ 重写一遍，体会内存管理与性能差异。

**经典阅读**这时候再去翻就会非常顺：Bob Nystrom 的 [《Crafting Interpreters》](https://craftinginterpreters.com/) 是和本指南思路最接近、可读性最高的免费英文书，第一部分用 Java 写树遍历解释器、第二部分用 C 写字节码 VM；想再深入语言理论，可以读 Andrew Appel 的《Modern Compiler Implementation》；想了解工业级实现，直接看 [LLVM Kaleidoscope 教程](https://llvm.org/docs/tutorial/)，它会带你用 LLVM IR 实现一门带 JIT 的小语言。

按这套路径走下来，你不仅写过编译器，还会知道每一行代码背后那条从字符流到机器执行的完整因果链——这正是编译原理这门课最该带给你的东西。祝你 hack 得开心。
