这是一个非常经典的推导，也是检验微积分基本功的试金石。

既然你暂时不想用拉普拉斯变换（特征函数）那种“作弊”般的快方法，而是选择硬啃积分，这很好！**配方法（Completing the Square）** 将是我们这里唯一的武器。

我们要计算 $Z = X + Y$，其中 $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$。

---

### 第一步：写出积分式

首先写出两个概率密度函数（PDF）：

$$f_X(x) = \frac{1}{\sqrt{2\pi}\sigma_1} e^{-\frac{(x-\mu_1)^2}{2\sigma_1^2}}$$

$$f_Y(y) = \frac{1}{\sqrt{2\pi}\sigma_2} e^{-\frac{(y-\mu_2)^2}{2\sigma_2^2}}$$

代入卷积公式 $f_Z(s) = \int_{-\infty}^{+\infty} f_X(x) f_Y(s-x) dx$：

$$f_Z(s) = \frac{1}{2\pi\sigma_1\sigma_2} \int_{-\infty}^{+\infty} \exp\left[ -\frac{(x-\mu_1)^2}{2\sigma_1^2} - \frac{(s-x-\mu_2)^2}{2\sigma_2^2} \right] dx$$

### 第二步：简化指数项（核心难点）

面对这一大坨指数，如果直接硬算会非常痛苦。我们要用**变量代换**来简化符号。

令 $x' = x - \mu_1$ （这是积分变量的偏移）

令 $s' = s - (\mu_1 + \mu_2)$ （这是总和相对于均值的偏移）

那么原来的 $s - x - \mu_2$ 就可以写成：

$$s - x - \mu_2 = s - (x' + \mu_1) - \mu_2 = (s - \mu_1 - \mu_2) - x' = s' - x'$$

现在指数部分 $E$ 变得清爽多了：

$$E = -\frac{1}{2} \left[ \frac{x'^2}{\sigma_1^2} + \frac{(s'-x')^2}{\sigma_2^2} \right]$$

我们的目标是：把关于 $x'$ 的项凑成一个完全平方式，因为我们要对 $x'$ 积分。

展开括号里的内容：

$$[\dots] = \frac{x'^2}{\sigma_1^2} + \frac{s'^2 - 2s'x' + x'^2}{\sigma_2^2}$$

合并同类项（按 $x'$ 降幂排列）：

$$[\dots] = x'^2 \left( \frac{1}{\sigma_1^2} + \frac{1}{\sigma_2^2} \right) - 2x' \left( \frac{s'}{\sigma_2^2} \right) + \frac{s'^2}{\sigma_2^2}$$

为了方便书写，我们通分一下括号里的系数：

$$\frac{1}{\sigma_1^2} + \frac{1}{\sigma_2^2} = \frac{\sigma_1^2 + \sigma_2^2}{\sigma_1^2 \sigma_2^2}$$

所以指数括号内变为：

$$\frac{\sigma_1^2 + \sigma_2^2}{\sigma_1^2 \sigma_2^2} x'^2 - \frac{2s'}{\sigma_2^2} x' + \frac{s'^2}{\sigma_2^2}$$

### 第三步：配方（Completing the Square）

这是整个推导最关键的一步。我们要把形如 $Ax^2 - Bx + C$ 的式子变成 $A(x - \frac{B}{2A})^2 + K$ 的形式。剩下的 $K$ 就是我们要提出来的系数。

这里：

- $A = \frac{\sigma_1^2 + \sigma_2^2}{\sigma_1^2 \sigma_2^2}$
- $B = \frac{2s'}{\sigma_2^2}$

我们需要凑出的中心点 $\frac{B}{2A}$ 是：

$$\frac{2s'/\sigma_2^2}{2(\sigma_1^2 + \sigma_2^2)/(\sigma_1^2 \sigma_2^2)} = s' \frac{\sigma_1^2}{\sigma_1^2 + \sigma_2^2}$$

**开始配方：**

$$[\dots] = A \left( x' - s'\frac{\sigma_1^2}{\sigma_1^2+\sigma_2^2} \right)^2 + \text{剩余项(Remainder)}$$

这个“剩余项”就是我们梦寐以求的 $Z$ 的分布指数。

$$\text{Remainder} = \text{原常数项} - A \times (\text{中心点})^2$$

$$\text{Remainder} = \frac{s'^2}{\sigma_2^2} - \left( \frac{\sigma_1^2 + \sigma_2^2}{\sigma_1^2 \sigma_2^2} \right) \left( s' \frac{\sigma_1^2}{\sigma_1^2 + \sigma_2^2} \right)^2$$

深吸一口气，化简这个剩余项：

$$= \frac{s'^2}{\sigma_2^2} - \frac{s'^2 \sigma_1^4}{(\sigma_1^2 \sigma_2^2)(\sigma_1^2 + \sigma_2^2)}$$

$$= \frac{s'^2}{\sigma_2^2} - \frac{s'^2 \sigma_1^2}{\sigma_2^2(\sigma_1^2 + \sigma_2^2)}$$

提取公因式 $\frac{s'^2}{\sigma_2^2}$：

$$= \frac{s'^2}{\sigma_2^2} \left( 1 - \frac{\sigma_1^2}{\sigma_1^2 + \sigma_2^2} \right)$$

$$= \frac{s'^2}{\sigma_2^2} \left( \frac{\sigma_1^2 + \sigma_2^2 - \sigma_1^2}{\sigma_1^2 + \sigma_2^2} \right)$$

$$= \frac{s'^2}{\sigma_2^2} \left( \frac{\sigma_2^2}{\sigma_1^2 + \sigma_2^2} \right) = \frac{s'^2}{\sigma_1^2 + \sigma_2^2}$$

**漂亮！** 剩余项非常简洁。

### 第四步：计算积分

现在我们将配方后的结果放回指数中。

指数 $E$ 分解为两部分：

$$E = -\frac{1}{2} \underbrace{A (x' - \dots)^2}_{\text{含 } x' \text{ 的部分}} - \frac{1}{2} \underbrace{\frac{s'^2}{\sigma_1^2 + \sigma_2^2}}_{\text{不含 } x' \text{ 的部分}}$$

原来的积分式 $f_Z(s)$ 变为：

$$f_Z(s) = \frac{1}{2\pi\sigma_1\sigma_2} \cdot \exp\left( -\frac{s'^2}{2(\sigma_1^2 + \sigma_2^2)} \right) \cdot \int_{-\infty}^{+\infty} \exp\left( -\frac{A}{2} (x' - \text{const})^2 \right) dx'$$

后面这个积分就是标准的高斯积分 $\int e^{-a x^2} dx = \sqrt{\frac{\pi}{a}}$。

这里 $a = \frac{A}{2} = \frac{\sigma_1^2 + \sigma_2^2}{2\sigma_1^2 \sigma_2^2}$。

所以积分值为：

$$\sqrt{\frac{\pi}{A/2}} = \sqrt{\frac{2\pi}{A}} = \sqrt{\frac{2\pi \sigma_1^2 \sigma_2^2}{\sigma_1^2 + \sigma_2^2}} = \sqrt{2\pi} \frac{\sigma_1 \sigma_2}{\sqrt{\sigma_1^2 + \sigma_2^2}}$$

### 第五步：合并系数，得到最终结果

现在把前面的常数系数和积分算出来的结果乘在一起：

$$f_Z(s) = \left( \frac{1}{2\pi\sigma_1\sigma_2} \right) \cdot \left( \sqrt{2\pi} \frac{\sigma_1 \sigma_2}{\sqrt{\sigma_1^2 + \sigma_2^2}} \right) \cdot \exp\left( -\frac{s'^2}{2(\sigma_1^2 + \sigma_2^2)} \right)$$

约分消项：

- $\sigma_1 \sigma_2$ 抵消了。
- $\sqrt{2\pi}$ 约掉一个。

剩下：

$$f_Z(s) = \frac{1}{\sqrt{2\pi}\sqrt{\sigma_1^2 + \sigma_2^2}} \exp\left( -\frac{s'^2}{2(\sigma_1^2 + \sigma_2^2)} \right)$$

把 $s'$ 换回 $s - (\mu_1 + \mu_2)$：

$$f_Z(s) = \frac{1}{\sqrt{2\pi(\sigma_1^2 + \sigma_2^2)}} \exp\left( -\frac{(s - (\mu_1 + \mu_2))^2}{2(\sigma_1^2 + \sigma_2^2)} \right)$$

### 结论

这正是一个新的正态分布的密度函数形式！

我们可以直接读出参数：

- **新均值**：$\mu_Z = \mu_1 + \mu_2$
- **新方差**：$\sigma_Z^2 = \sigma_1^2 + \sigma_2^2$

**推导心得：**

你看，虽然过程繁琐，但核心思想只有一个：**高斯分布具有“再生性”**。

无论你怎么在指数上做配方，二次项系数 $x^2$ 永远存在，所以积分算出来永远是常数；剩下的关于 $s$ 的项也永远是二次的（$s^2$），这就保证了结果依然是高斯分布。

这比均匀分布推导出来的 Irwin-Hall 分布（分段多项式）要“稳固”得多，这也是正态分布在自然界称王的原因之一：**怎么加都还是它自己。**
