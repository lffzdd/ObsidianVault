# 2008金融危机

## 当前理解

2008 年危机的链条：住房贷款证券化 → 两房和评级公司放大风险 → CDS 让保险公司敢“接盘” → 杠杆导致机构立即破产；AIG 被救、雷曼倒下，事后“大到不能倒/不能罚”，补救法案逐渐被改写。
