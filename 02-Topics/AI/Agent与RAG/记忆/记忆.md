# 记忆

## 当前理解

Agent 的记忆分短期（上下文窗口）和长期（外部存储）。LangChain 的记忆只是把历史拼回 prompt；Letta 走 OS 式分层记忆（核心/归档，由模型自己换页），Mem0 走“抽取事实—检索注入”的路线。
