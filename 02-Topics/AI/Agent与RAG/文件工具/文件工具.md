# 文件工具

## 当前理解

Agent 读写文件的“三件套”是 glob（按路径找文件）、grep/ripgrep（按内容找）、Read/Edit（精确读写），并给模型一个起点。Claude Code 的会话记录（opus / sonnet 两版）展示了它实际如何组合这些工具理解一个仓库。
