```python
def forward(self, x: Tensor) -> Tensor:
    embed_dim = x.shape[2]  # x.shape = [batch_size, seq_len, embed_dim]
    seq_len = x.shape[1]
    
    pos_vec = torch.zeros(seq_len, embed_dim, device=x.device)
    
    for pos in range(seq_len):  # seq中第pos个token
        for i in range(embed_dim):  # token向量的第i维度
            if i % 2 == 0:  # 如果是第奇数个维度
                pos_vec[pos, i] = torch.sin(pos / (10000 ** (i / embed_dim)))
            else:
                pos_vec[pos, i] = torch.cos(pos / (10000 ** ((i - 1) / embed_dim)))
    return x + pos_vec  # 自动广播机制
```

```python
def forward(self, x: Tensor) -> Tensor:
    batch_size, seq_len, embed_dim = x.shape
    
    # 位置索引 [seq_len, 1]
    pos = torch.arange(seq_len, device=x.device).unsqueeze(1)
    
    # 维度索引 [embed_dim // 2]
    div_term = 10000 ** (torch.arange(0, embed_dim, 2, device=x.device) / embed_dim)
   
	"""
	## 关键：`pos / div_term` 会广播！
	```python
	pos.shape       # [128, 1]
	div_term.shape  # [256]
	
	广播：
	pos:      [128,   1]
	div_term: [  1, 256]  ← 自动补 1
	结果:     [128, 256]
	```
	""" 
	
    # 创建位置编码 [seq_len, embed_dim]
    pos_encoding = torch.zeros(seq_len, embed_dim, device=x.device)
    pos_encoding[:, 0::2] = torch.sin(pos / div_term)  # 偶数位置
    pos_encoding[:, 1::2] = torch.cos(pos / div_term)  # 奇数位置
    
    return x + pos_encoding
```

## 逐行解释向量化位置编码

这段代码和你的循环版本**做的事情完全一样**，只是用向量运算替代了循环，更高效。

---

### 第 1 步：获取形状

```python
batch_size, seq_len, embed_dim = x.shape
# 例如：batch_size=32, seq_len=128, embed_dim=512
```

### 第 2 步：创建位置索引

```python
pos = torch.arange(seq_len, device=x.device).unsqueeze(1)
```

分解：

```python
# torch.arange(seq_len) 生成 [0, 1, 2, ..., seq_len-1]
torch.arange(128)  # [0, 1, 2, ..., 127]，形状 [128]

# .unsqueeze(1) 在第 1 维添加一个维度
# [128] → [128, 1]

pos = [[0],
       [1],
       [2],
       ...
       [127]]  # 形状 [128, 1]
```

### 第 3 步：创建除数项

```python
div_term = 10000 ** (torch.arange(0, embed_dim, 2, device=x.device) / embed_dim)
```

分解：

```python
# torch.arange(0, embed_dim, 2) 生成偶数索引 [0, 2, 4, ..., embed_dim-2]
torch.arange(0, 512, 2)  # [0, 2, 4, ..., 510]，形状 [256]

# / embed_dim
[0, 2, 4, ..., 510] / 512  # [0, 0.0039, 0.0078, ..., 0.996]

# 10000 ** (...)
10000 ** [0, 0.0039, ...]  # [1, 1.018, 1.036, ..., 9659]

div_term.shape  # [256]（embed_dim 的一半）
```

**这就是公式里的 `10000 ^ (2i / embed_dim)`**

### 第 4 步：计算 sin 和 cos

```python
pos_encoding[:, 0::2] = torch.sin(pos / div_term)  # 偶数位置
pos_encoding[:, 1::2] = torch.cos(pos / div_term)  # 奇数位置
```

#### 关键：`pos / div_term` 会广播！

```python
pos.shape       # [128, 1]
div_term.shape  # [256]

# 广播：
# pos:      [128,   1]
# div_term: [  1, 256]  ← 自动补 1
# 结果:     [128, 256]
```

#### 索引语法 `0::2` 和 `1::2`

```python
[:, 0::2]  # 所有行，列从 0 开始，步长 2（偶数列：0, 2, 4, ...）
[:, 1::2]  # 所有行，列从 1 开始，步长 2（奇数列：1, 3, 5, ...）
```

### 完整流程图

```
位置编码公式：
PE(pos, 2i)   = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

pos:       [128, 1]       位置索引
div_term:  [256]          = 10000^(2i/d)

pos / div_term: [128, 256]  广播结果

sin(pos / div_term): [128, 256] → 填入偶数列
cos(pos / div_term): [128, 256] → 填入奇数列

pos_encoding: [128, 512]  最终位置编码
```

### 总结

| 概念 | 说明 |
|------|------|
| `unsqueeze(1)` | 添加维度，为广播做准备 |
| `arange(0, n, 2)` | 生成偶数序列 |
| `[:, 0::2]` | 选择偶数列 |
| `[:, 1::2]` | 选择奇数列 |
| 广播 | `[128, 1] / [256]` → `[128, 256]` |
