## PyTorch 广播机制（Broadcasting）详解

### 什么是广播？

广播是一种**自动扩展张量形状**的机制，让不同形状的张量可以进行运算，而**不需要手动复制数据**。

---

### 最简单的例子

```python
import torch

a = torch.tensor([1, 2, 3])  # 形状 [3]
b = 10                        # 标量

c = a + b  # → [11, 12, 13]
```

**发生了什么？**
- `b = 10` 被 " 广播 " 成 `[10, 10, 10]`
- 然后 `[1, 2, 3] + [10, 10, 10] = [11, 12, 13]`

---

### 广播规则（从右往左对齐）

**规则：从最后一维开始比较，每一维必须满足以下条件之一：**

1. ✅ 维度相同
2. ✅ 其中一个是 1
3. ✅ 其中一个不存在（维度数量不同）

---

### 规则图解

```
情况 1：维度相同 ✅
A: [3, 4]
B: [3, 4]
→ 可以运算

情况 2：其中一个是 1 ✅
A: [3, 4]
B: [1, 4]  ← B 的第 0 维是 1
→ B 被广播成 [3, 4]

情况 3：维度数量不同 ✅
A: [3, 4]
B:    [4]  ← B 少一维
→ B 被理解为 [1, 4]，然后广播成 [3, 4]

情况 4：不兼容 ❌
A: [3, 4]
B: [2, 4]  ← 3 ≠ 2，且都不是 1
→ 报错！
```

---

### 详细例子

#### 例子 1：向量 + 标量

```python
a = torch.tensor([1, 2, 3])  # [3]
b = 10                        # 标量 → 理解为 [1]

# 广播过程
# a: [3]
# b: [1] → 广播为 [3]

a + b  # [11, 12, 13]
```

#### 例子 2：矩阵 + 行向量

```python
a = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])   # [2, 3]
b = torch.tensor([10, 20, 30])  # [3]

# 广播过程
# a: [2, 3]
# b:    [3] → 理解为 [1, 3] → 广播为 [2, 3]

a + b
# [[11, 22, 33],
#  [14, 25, 36]]
```

#### 例子 3：矩阵 + 列向量

```python
a = torch.tensor([[1, 2, 3],
                  [4, 5, 6]])   # [2, 3]
b = torch.tensor([[10],
                  [20]])        # [2, 1]

# 广播过程
# a: [2, 3]
# b: [2, 1] → 广播为 [2, 3]

a + b
# [[11, 12, 13],
#  [24, 25, 26]]
```

#### 例子 4：你的位置编码场景 ⭐

```python
x = torch.randn(32, 128, 512)        # [batch, seq, embed]
pos_vec = torch.zeros(128, 512)      # [seq, embed]

# 广播过程
# x:       [32, 128, 512]
# pos_vec:     [128, 512] → 理解为 [1, 128, 512] → 广播为 [32, 128, 512]

x + pos_vec  # [32, 128, 512] ✅
```

---

### 广播的可视化

```
x:        [32, 128, 512]
           ↑
pos_vec:  [ 1, 128, 512]  ← 自动补 1
           ↓
广播后:   [32, 128, 512]  ← 复制 32 份
```

但**实际上不复制内存**！PyTorch 只是假装有 32 份，节省内存。

```
x (输入):
┌─────────────────────────────────┐
│ Batch 0: [seq_len, embed_dim]   │
│ Batch 1: [seq_len, embed_dim]   │
│ Batch 2: [seq_len, embed_dim]   │
│ ...                             │
└─────────────────────────────────┘

pos_vec (位置编码):
┌─────────────────────────────────┐
│ [seq_len, embed_dim]            │  ← 只需要一份！
└─────────────────────────────────┘

x + pos_vec (广播后):
┌─────────────────────────────────┐
│ Batch 0 + pos_vec               │
│ Batch 1 + pos_vec               │  ← 自动应用到每个 batch
│ Batch 2 + pos_vec               │
│ ...                             │
└─────────────────────────────────┘
```

---

### 常见广播模式

| 形状 A | 形状 B | 结果形状 | 说明 |
|--------|--------|----------|------|
| `[3]` | `[1]` | `[3]` | 标量广播 |
| `[2, 3]` | `[3]` | `[2, 3]` | 行向量广播 |
| `[2, 3]` | `[2, 1]` | `[2, 3]` | 列向量广播 |
| `[32, 128, 512]` | `[128, 512]` | `[32, 128, 512]` | 你的位置编码 |
| `[32, 128, 512]` | `[512]` | `[32, 128, 512]` | LayerNorm |

---

### 广播失败的例子

```python
a = torch.randn(3, 4)
b = torch.randn(2, 4)

a + b  # ❌ RuntimeError!
# 因为 3 ≠ 2，且都不是 1
```

---

### 总结

| 概念 | 说明 |
|------|------|
| **什么是广播** | 自动扩展张量形状以进行运算 |
| **规则** | 从右往左对齐，维度相同或其中一个是 1 |
| **优点** | 代码简洁、不复制内存、高效 |
| **你的代码** | `x + pos_vec` 自动把 `[seq, embed]` 广播到 `[batch, seq, embed]` |

广播是深度学习代码简洁高效的关键！🎯
