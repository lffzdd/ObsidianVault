# 目标检测

## 当前理解

目标检测从滑窗 + HOG 起步，到 R-CNN 系列（selective search → Fast R-CNN 共享特征 → Faster R-CNN 的 RPN → Mask R-CNN 的 RoI Align + Mask 分支），再到单阶段的 YOLO；IoU、偏移量编码和检测指标贯穿始终，工程上关注 YOLO 轻量化。
