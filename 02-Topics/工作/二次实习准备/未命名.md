## 月度规划概览

## 第 1 个月：Go 入门 + 复习基础 + 刷题起步

目标：快速上手 Go 语法和基本并发，把 C++ 的思维迁移过来。[[reddit](https://www.reddit.com/r/golang/comments/10mo159/jr_go_developers/)]​

- Go 语法与标准库
    
    - 安装 Go，熟悉模块（go mod）、包管理。
        
    - 语法：变量、函数、结构体、接口、方法、切片、map、defer、错误处理。
        
    - 并发入门：goroutine、channel、select 的基本用法。
        
- 利用 C++ 基础迁移：
    
    - 自己用 Go 写一遍你以前用 C++ 写过的简单小程序（如：LRU、栈队列、二叉树遍历）。
        
- 刷题：
    
    - 每天 1–2 题 LeetCode Easy/Medium，先把数组、链表、哈希表、二分搞熟。
        
- 计算机基础：
    
    - 每天看一点计网（TCP/UDP、HTTP）、操作系统（进程线程、锁）、数据库（索引、事务）。
        

第 1 个月结束时，你应该能：

- 用 Go 写小命令行程序、基本数据结构。
    
- 看懂简单的 Go Web 框架示例代码。
    

---

## 第 2 个月：Go Web 后端入门 + 第一个小项目

目标：跑通一个简单的 Web 服务，开始搭建项目骨架。[[nowcoder](https://www.nowcoder.com/discuss/546134793096900608)]​

- 学一个主流框架（推荐 Gin）：
    
    - 路由、参数解析、中间件、日志。
        
    - JSON 序列化、错误处理。
        
- 数据库：
    
    - 学 MySQL 基本操作（建表、增删改查、索引）。
        
    - 用 GORM 或 database/sql 连接 MySQL，实现简单的 CRUD。
        
- 第一个小项目（建议）：
    
    - 用户 + 任务管理系统 / 简单博客系统。
        
    - 功能要求：注册登录、创建/编辑/删除资源、分页查询。
        
- 刷题：
    
    - 继续 Easy + 部分 Medium，加入链表、二叉树、DFS/BFS。
        

第 2 个月结束时，你应该能：

- 搭一个简单的 Go + Gin + MySQL 项目，API 跑通。
    
- 用 Postman/浏览器测试接口。

## 第 3 个月：完善第一个项目 + 引入 Redis/鉴权

目标：把第一个项目升级成“能写在简历上的成品”。[[nowcoder](https://www.nowcoder.com/discuss/546134793096900608)]​

- 在现有项目上加：
    
    - 登录鉴权（JWT 或 Session）。
        
    - Redis 用于缓存或会话存储。
        
    - 简单权限控制（例如只能操作自己的数据）。
        
- 工程化：
    
    - 项目结构拆分成多层（router/service/repository）。
        
    - 配置管理（config 文件、环境变量）。
        
    - 日志 & 错误处理规范。
        
- 部署：
    
    - 用 Docker 容器化（Dockerfile + docker-compose）。
        
    - 尝试部署到一台云服务器（阿里云/腾讯云轻量应用）。
        
- 写 README：
    
    - 项目介绍、功能、技术栈、如何运行、你负责的部分。
        
- 刷题：
    
    - Medium 为主，开始接触简单 DP、双指针、高频题。
        

第 3 个月结束时，你应该有：

- 一个能在线跑的项目链接 + 完整 README。
    
- 对 Go Web 开发有基本全流程理解。

## 第 4 个月：第二个项目（偏业务/偏实战）+ 并发实践

目标：做第二个更贴近业务的项目，展示你对并发、性能的理解。[[nowcoder](https://www.nowcoder.com/discuss/546134793096900608)]​

项目建议选一个下面类型之一：

- 简单电商/订单系统：
    
    - 商品、购物车、订单、库存扣减（可以模拟），强调接口设计。
        
- 简易消息/评论系统：
    
    - 支持用户发帖、评论、点赞，做列表分页、热门排序。
        
- 简单网关/短链接服务：
    
    - URL 短链生成 + 访问统计，需要考虑并发、唯一性。
        

在这个项目里刻意练：

- 并发：
    
    - 用 goroutine + channel 处理异步任务（发送邮件、写日志、统计）。
        
- 性能/优化：
    
    - 加缓存（Redis）减少数据库压力。
        
    - 给出一些简单压测结果（例如使用 ab/hey）。
        

同时：

- 刷题：
    
    - 保持每周 8–10 题，集中在高频 Medium，常见题型轮转。
        
- 计算机基础：
    
    - 系统性整理你的「八股」笔记，按模块总结。
        

第 4 个月结束时，你应该有：

- 第二个项目，能讲出「业务背景 + 设计方案 + 难点和优化」。
    
- 一套可反复复习的八股文笔记。

## 第 5 个月：简历打磨 + 模拟面试 + 算法冲刺

目标：开始为投简历做准备。cnblogs+1

- 简历：
    
    - Control 在一页：教育背景 + 项目经历 + 技能栈。
        
    - 项目描述用「解决什么问题 → 用了什么技术 → 达到什么效果」的句式。
        
- 刷题重点：
    
    - 回顾做过的题，把不会的题型再做两遍。
        
    - 模拟真实面试：计时写题 + 当场讲思路。
        
- 基础问答准备：
    
    - 计网（TCP 三次握手、四次挥手、HTTP 状态码）。
        
    - 操作系统（进程线程、死锁、内存管理）。
        
    - 数据库（索引、事务隔离级别、SQL 优化常识）。
        
    - Go 八股（goroutine、GMP 模型、逃逸分析、GC 基本概念等）。
        
- 面试技巧：
    
    - 准备 1 分钟和 3–5 分钟的自我介绍版本。
        
    - 每个项目都准备好「一个难点 + 一次优化 + 一个踩坑故事」。[[nowcoder](https://www.nowcoder.com/discuss/546134793096900608)]​

目标：边投简历边查漏补缺。cnblogs+1

- 可以加一个小改进：
