**ai**: 08 年金融危机的“直接原因”，可以概括为一句话：**美国住房相关资产的信用崩塌，引发以 Repo/短期批发融资为核心的流动性挤兑，最终把高杠杆机构推入连锁违约与火售（fire sale）**。

更具体地拆成一条“触发链”：

- **房价见顶下跌 + 次贷违约率飙升（信用事件的源头）**  
  房价不再上涨后，很多次级按揭借款人无法再通过“再融资”续命，违约迅速上升，抵押品（房子）处置价值也下降。

- **MBS/CDO 等结构化产品估值暴跌（资产端瞬间缩水）**  
  这些产品现金流来自房贷。违约上升后，市场对其风险重估，价格大跌；并且因为交易不活跃，估值更容易“跳崖”，形成恐慌性折价。

- **按市值计价（mark-to-market）触发资本压力（会计/监管放大器）**  
  资产价格一跌，机构账面净资本立刻变薄，资本充足/杠杆约束变紧。

- **Repo “加保证金/提高折扣率（haircut）” + 不续借（融资端挤兑）**  
  债权人开始要求更多抵押品或直接不借隔夜资金。对“借短买长”的投行/影子银行来说，这相当于**存款挤兑**。

- **为筹现金被迫抛售资产（火售）→ 价格继续下跌 → 更多保证金追缴（死亡螺旋）**  
  抛售压低价格，进一步触发追加保证金和更多不续借，连锁传染。

- **关键节点：雷曼倒闭（2008/9）使对手方信任崩塌，恐慌全面化**  
  雷曼破产把“原来大机构也会倒”的预期钉死，货币市场基金、同业拆借、CDS/对手方风险都一起失灵，危机从“房地产信用问题”升级为“全面流动性危机”。

**user**: 房价不动了,然后呢?
[Context: Notes: 01-Daily Notes/2026-03-31/金融 3 - 为什么立马破产.md]
[Timestamp: 2026/03/31 23:47:31]

**ai**: 房价一旦“不再上涨”（哪怕只是横盘），次贷体系里很多原本靠“滚动续命”的机制会立刻失效，后面通常按这条链条走：

- **再融资通道断掉（Refinance 断流）**  
  很多次贷/Alt-A 借款人一开始拿的是“前两年低利率、之后利率跳升”的贷款（teaser rate / reset）。  
  房价上涨时，他可以到期前再融资：用更高的房价做抵押，重新借一笔把旧贷还掉。  
  房价不涨后，银行不愿意按更高估值放贷，借款人也很难再融资。

- **负资产出现（Negative equity）→ 违约激励上升**  
  房价一跌，房子市值 < 房贷余额，卖房也还不清。很多人会选择“战略性违约”（直接不还了），违约率显著上升。

- **现金流断裂 → MBS/CDO 真实损失开始落地**  
  房贷违约意味着对应的按揭现金流（利息+本金）减少；止赎卖房的回收率又因为房价下跌而更低。  
  结果是 MBS（房贷支持证券）和 CDO 的底层现金流恶化，从“账面风险”变成“真亏钱”。

- **市场重估这些证券 → 价格暴跌（估值塌方）**  
  一旦大家意识到违约不是个别现象，而是系统性上升，买方就要求更高风险补偿，甚至没人敢接盘，价格会跳水。

- **进入金融机构的“致命环节”：抵押品变差 → Repo 提高 haircut/不续借**  
  投行用 MBS/CDO 做抵押去借隔夜 Repo。你抵押品从“看起来很安全”变成“可能大亏”，出借方会：  
  - 要你补更多抵押品/现金（追加保证金、提高 haircut）  
  - 或者干脆第二天不借了  
  这就等价于对投行发生“挤兑”。

- **被迫抛售 → 火售压低价格 → 更大保证金追缴（死亡螺旋）**  
  为了筹现金只能卖资产；但大家都在卖，价格更低，于是“资产价格跌—融资更难—再卖”的螺旋加速，最后出现破产（如雷曼）。

一句话总结“房价不动了然后呢”：  
**房价不涨 → 借款人无法再融资 → 违约上升 → MBS/CDO 现金流恶化与价格崩 → 抵押融资（Repo）挤兑 → 火售/连锁倒闭。**
