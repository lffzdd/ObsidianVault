**ai**: 在 Obsidian 里，**普通的三反引号代码块（```）默认不能折叠**（除非你装了相关插件或主题/CSS 做了增强）。

你有几种可行替代方案：

- 用 **Callout** 来包住代码（Callout 可以折叠）  
  ```markdown
  > [!note]- 这一段代码（可折叠）
  > ```python
  > print("hello")
  > ```
  ```
  说明：`[!note]-` 里的 `-` 表示默认折叠；如果用 `+` 通常表示默认展开（取决于主题/版本行为）。

- 用 **HTML 的 <details>**（也能折叠）
  ```markdown
  <details>
  <summary>展开/收起：代码</summary>

  ```python
  print("hello")
  ```

  </details>
  ```
  兼容性一般不错，但少数主题/插件可能对渲染有影响。

- 装插件实现“代码块折叠”
